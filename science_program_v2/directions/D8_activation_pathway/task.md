# D8 — 激活通路结论的现实条件存活性（v1 C 方向未决）

## 模糊问题

v1 C01–C03 在**对称零 bias、固定/learned 单层特征、MSE**下建立了小尺度 SiLU 的偶通路 scale² 抑制与无标签干预收益。这些结论在更现实的条件下还剩多少：非零 bias、非对称输入分布、多层、分类 CE、小批量 SGD？

## 已知起点（只读）

- v1 C01/C02/C03（`../../../references/science_program_v1/studies/`）：奇偶分解 odd=z/2、even≈z²/4（小 z）；封存 dim8 干预 MSE .9526→.00428、1.1365→.01499；learned hidden 部分逃出瓶颈（scale .3 SiLU .0068 胜 ReLU .139）。
- v1 KB C0001 的 boundary 字段列了全部未测范围。
- 主线 K1056（GELU/SiLU vs ReLU 的经验倾向）、K1197（CE 下晚期 test 变差）。

## 破坏严格奇偶分离的因素（每个都是子问题）

1. 非零 bias：even/odd 通道混合，scale² 抑制律如何修正？
2. 非对称输入分布（shifted/skewed）：C03 已用 shifted_gaussian 做过部分，系统化。
3. 多层：逐层奇偶混合的传递；有没有逐层可测的"偶能量占比"。
4. CE/分类 + 小批量 SGD：干预（偶能量匹配）是否仍可实施、是否有收益。

## 什么算进展

- 每个因素给出"结论保留/修正/失效"的受控测量（配对设计，固定其余因子）。
- 修正律优先于二分结论：如 bias≠0 时抑制指数从 2 变成什么，随 bias 尺度如何变。
- 至少一次封存前瞻：用修正律预测新条件下的干预收益。

## 首轮建议

从因素 1（非零 bias）开始：复用 C01 的固定特征设置，加 bias 扫描，测偶/奇核能量与拟合速度，看 scale² 律的形变。单层、MSE、全批量，保持最小改动。
