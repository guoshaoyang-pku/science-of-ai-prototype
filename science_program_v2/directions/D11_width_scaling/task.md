# D11 — 宽度与样本量的标度律

## 模糊问题

D3 建立了"完整目标加权谱决定拟合预算、单一标量不够"，但只在 n=d=9 的固定特征系统里。描述量随 width、n、输入维度如何标度？有没有干净的指数律？什么时候进入 lazy/NTK 式标度、什么时候离开？

## 已知起点（只读）

- D3（`../D3_capacity_resolution/report.md`）：Tε(μᵧ,η) 描述量；匹配 Rayleigh/trace/有效秩的目标预算仍差 2.9–8.9 倍。
- D4：谱比决定的 sigmoid 边界（n=d=2 系统）。
- v1 B02/B03：width8/32/64 的核漂移与 Rayleigh 测量；v1 A03：width64/192 配对。
- 已知理论（不作为新发现）：NTK lazy regime 的 width 标度、神经缩放律经验拟合。本方向价值=在受控小系统里测出描述量的指数并检验离开 lazy 的边界。

## 子问题

1. 固定特征下 Tε 对 width/n 的标度指数（谱构造固定时）；目标加权谱质量随 n 的集中行为。
2. learned 特征下同一描述量是否仍有幂律？指数如何随训练阶段漂移？
3. D3 的"标量不够"结论在更大 width 下是变强还是变弱（lazy 极限里 Rayleigh 是否重新充分）？
4. n/d 比例（过参数化度）与拟合预算的关系。

## 什么算进展

- 至少一个描述量的标度指数（带拟合误差与适用范围），在 ≥3 个 decade 的 width 或 n 上稳定。
- lazy↔rich 的受控边界测量：同一目标下何时 Rayleigh 重新充分。
- 一次封存前瞻：用指数律外推到未测 width，报告误差。

## 首轮建议

从子问题 1+3 入手：复用 D3 r012 的谱构造（λᵢ=i⁻ᵖ），把 d 从 9 扩到 8–512（2 的幂网格），固定目标构造规则，测 T₁% 对 d 的标度；同谱下比较"仅 Rayleigh 预测"与"完整谱预测"的误差随 d 的变化。全批量、固定特征，一轮可完成。
