# 固定样本记账数的零填充对照

本轮只问一个问题：在固定特征谱 λᵢ=i⁻¹、d=8..8192 二倍网格、中间/首尾两种目标、η=.5、momentum=0、无 weight decay、ε=.01 下，把样本数从 n=d 改为 n=8192，并将前 d 个样本按 √n 缩放、其余样本置零，首次达到阈值的整数预算是否保持旧 n=d 结果。

## 预注册与执行

预注册和 pinned 源码在提交 cc2f552 中冻结，训练前结果目录为空；随后才运行参数更新。旧科学收尾 37d1ea6 与 145 个研究文件逐字匹配，66 个 metadata/NPZ hash 通过。旧目录没有保存 final_commit_verification.json，本轮如实记录缺失并补充核验。恢复运行没有覆盖成功文件，旧 145 个文件与新 133 个结果文件的 hash/mtime 均未改变。

11 个 d × 2 个目标 × 3 个坐标 seed 共 66 个新 cell，全部在 5d 上限前达到阈值，无删失。每个 cell 使用前 d 个非零样本，后 8192−d 行为零；参数梯度分母为 n，特征和目标幅度为 √n。累计实验计算 3.714065790991299 秒。

预注册前写源码时出现过工具字符串/换行语法错误，修正后 AST/compile 检查通过再提交；错误调用没有训练。独立只读复算第一次因阈值循环重复解压 NPZ 而被中止，保存原因；修正为每个 NPZ 成员只读一次后复算通过。未修改预注册、runner、analysis 或成功 cell。

## 解释与边界

零填充在样本 Gram 中只增加 n−d 个零模态，目标在这些模态上的权重为零；归一化参数 Hessian、Xᵀy/n、L0 与参数目标保持一致。这一对照消除了预算依赖 n=d 损失记账的解释。非零样本数仍为 d，没有增加独立数据。seed 只改变 signed permutation 坐标，不是独立数据重复，不计算 seed 置信区间。

结果只适用于当前固定特征、谱尾规则、目标规则、float64、全批量 SGD 和 development 条件。它不能推出独立样本增加无效，也不能给出 learned width、随机特征集中、核漂移或 lazy↔rich 边界。下一小问题保持 n=8192/目标/坐标/优化器，只将 λᵢ改为 i⁻¹/h_d 以固定 trace，先注册 T/(d h_d) 数值判据再训练。
