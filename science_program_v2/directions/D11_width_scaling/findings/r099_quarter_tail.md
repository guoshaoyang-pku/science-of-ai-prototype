# 同 Rayleigh、固定双模态权重的预算反例

同谱、同 Rayleigh 的预算差在两个占用模态都随 d 缩放、权重不消失时仍存在。33 个同坐标配对的新/中间目标 1% 预算比为 1.823860087–1.857142857；单 Rayleigh 预测低估 45.171233%–46.153846%。两项预注册预测均得到支持。

本轮只检验这一个问题。保持 n=8192、非零样本数 d、d=8–8192 的 11 个二倍网格、trace=1 谱 λᵢ=1/(i h_d)、零初始化、float64 全批量半平方损失 SGD η=0.5、无动量、无权重衰减和 ε=0.01。新目标在 i=d/4 与 i=d 放 1/3、2/3 能量，其余为零。旧中间目标的特征值、置换、符号直接读取，同坐标的旧预算只读。新增 11 条件×3 坐标 seed=33 cell；不重跑旧成功结果，也不运行失效草稿。

## 解释与边界

新目标的两个占用特征值为 4/(d h_d) 和 1/(d h_d)，能量固定为 1/3 与 2/3。它与中间目标的 m₁ 都为 2/(d h_d)，初始损失都是 0.5。结果排除“预算反例必须用不随 d 缩放的极快模态与消失的快权重”这一必要条件。固定特征中，同谱和同 m₁ 仍不足以确定拟合预算。

新目标 m₂=6/(d²h_d²)，中间目标 m₂=4/(d²h_d²)；参数目标范数平方分别为 3d h_d/4 与 d h_d/2。这些量随目标改变，不能独立归因慢模态质量或任一中介。本轮没有独立随机数据、真实网络宽度、特征学习、核漂移、lazy↔rich、泛化或封存 OOD，也不从三个离散 ε 推连续阈值规律。

全部属于 development。数值区间来自已见旧反例的粗略判断；注册前没有算新整数预算或新极限根。不把这种验证称为封存前瞻。新问题是受控反例的边界扩展，不是发现新的谱递推。
