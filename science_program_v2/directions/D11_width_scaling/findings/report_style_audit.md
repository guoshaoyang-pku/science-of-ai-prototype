原谱两条幂律、同 Rayleigh 预算不合并、固定 n 零填充预算不变、trace=1 的 d h_d 缩放以及三个离散阈值的误差结论均保持。单 Rayleigh 对首尾的低估、最小相邻区间的指数越界、失效准备阶段与旧 d 幂律对新谱的描述性偏差均保持。没有把已知谱递推登记为新发现，也没有把坐标 seed 写成独立数据重复。

目标参数范数与二阶谱矩未匹配的混杂保留。归一化同时改变初始梯度与参数目标范数的边界保留。固定特征不能识别真实宽度、核漂移或 lazy↔rich 阈值的限制保留。未测网格外、连续 ε、独立数据与封存 OOD 的限制保留。

原未决问题中“下一小问题优先零新训练”的建议与“下一轮应改选新的受控谱/目标或独立数据问题”同时存在。此次只调整呈现顺序，并原样保留旧候选句；不替研究会话选择问题。
