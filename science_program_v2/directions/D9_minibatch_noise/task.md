# D9 — 小批量噪声与有效时间

## 模糊问题

现有全部规律（U 换算、逐模态递推、sigmoid 边界、t*≈n/σ²）都建立在全批量梯度上。小批量随机梯度带来的噪声如何改写这些规律？噪声是等效学习率重标度、谱滤波，还是别的机制？

## 已知起点（只读）

- D1（`../D1_u_effective_time/report.md`）：全批量下逐模态精确递推、启动修正适用域、|g| 纯标定结论。
- D2：t* ≈ C·(n/σ²)^b 经验律（全批量 GD）。
- D4：谱时间尺度比 ≤10 单 logistic 成立、≥30 失败的边界。
- v1 B01：Adam 坐标依赖。主线 K1001 的 batch 是经验变量（b16–b64），未受控。
- 已知理论（不作为新发现）：SGD≈GD+噪声的扩散近似、有效学习率 renormalization。本方向价值=受控区分哪些全批量规律在匹配噪声下存活。

## 子问题

1. batch 从全批量降到 B 时，逐模态递推的偏差什么时候可忽略、什么时候系统性偏移？偏移量与 η·tr(H)/B 的关系？
2. D2 的 t*≈n/σ² 律在 mini-batch 下如何移动？噪声方差 σ²_grad 与标签噪声 σ² 是否可加？
3. sigmoid 拟合边界（谱比 10–30 之间）是否被 batch 噪声移动？
4. 同噪声尺度下，Adam 与 SGD 的等效时间是否收敛到同一描述？

## 什么算进展

- 至少一条全批量规律在受控 mini-batch 下的存活/修正测量（配对设计：同 seed 同数据，只改 batch）。
- 噪声强度 → 规律参数移动的定量关系（经验公式可，附系数与误差）。
- 一次封存前瞻：用修正公式预测新 (B, η, σ²) 组合。

## 首轮建议

从子问题 2 入手：复用 D2 的 r003 合同（固定特征 ReLU、η=.3、n/σ² 网格），只改全批量为 B=8/32 的 mini-batch GD，测 t* 移动与经验律系数变化。配对 seed，先 development。
