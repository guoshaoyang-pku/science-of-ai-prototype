# D12 — 延迟跃迁与级联 sigmoid

## 模糊问题

D4 测得单 logistic 在谱时间尺度比 ≥30 时失败。失败之后曲线长什么样：是每个时间尺度一段的级联 sigmoid，还是平台+骤降的延迟跃迁（grokking 形状）？跃迁时刻和陡度有没有可预测公式？

## 已知起点（只读）

- D4（`../D4_sigmoid_training_curve/report.md`）：谱比 1/3/10 通过、30/100 失败；拟合 t50 相对真实半衰期偏差随谱比增大到 +72%；级联 sigmoid 明确列为未测。
- D2：test 风险 U 型 = 信号下降 + 噪声上升的叠加；train 侧的级联结构会如何映射到 test 侧未测。
- 已知文献概念（不作为新发现）：grokking、延迟泛化、多阶段下降。本方向价值=在完全可控的固定特征/小 MLP 系统里给出跃迁时刻与陡度的预测公式和成立边界。

## 子问题

1. 谱比 30/100 的失败曲线用双 logistic 级联拟合：每段的 t50/陡度是否由对应模态的解析半衰期预测？
2. 三模态系统：级联段数=可分辨时间尺度数的规律是否成立？段 merging 的临界谱比？
3. momentum/η 改变时级联结构如何移动（与 D1 启动修正衔接）？
4. learned 特征下（小 MLP）是否出现真延迟跃迁（平台远长于任何线性模态时间尺度）？出现条件？

## 什么算进展

- 级联 sigmoid 的参数公式：每段 t50、陡度由谱量预测，在谱比 30/100 上验证（development），再封存一个新谱比前瞻检验。
- 段 merging 临界谱比的测量（10–30 之间 D4 未扫描的空档）。
- 若发现 learned 特征的真延迟跃迁：给出最小复现 recipe 与出现边界。
