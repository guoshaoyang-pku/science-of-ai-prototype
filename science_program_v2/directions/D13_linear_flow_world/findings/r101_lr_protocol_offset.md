# r101：降低学习率能否消除无 skip 链的协议偏移

## 结论

降低学习率改善了原 step 协议的 A/B 一致性，但没有建立稳定的相变时间标定。P1 通过 3/3；固定时间轴的收敛预测 P2 仅通过 2/3，被推翻。最小学习率的 A 时间跨 seed 变异系数为 0.276924，仍超过旧稳健性参考值 0.25。

## 小问题与冻结

只问一个问题：固定深度 4、每个 seed 的初始矩阵、输入和目标后，降低学习率是否能消除上一轮的 A/B 偏移？选择上一轮分歧最大的深度，是 development 条件选择；不是封存 OOD。

预注册与两份执行/分析源码同在提交 657a4d491ce6e6d71642dc691a7fe45dc63c76c7 冻结，早于首个新 cell 21.471142 秒。新学习率结果在此之前未训练或拟合。已有方向报告符合八节骨架，无需开头重排。无 inbox 文件，故无处理标记。

## 条件与结果

深度 4、隐藏宽度 32、128×4 固定高斯输入、4×4 正交目标、sigma=0.8、float64、全批量 GD、无动量或衰减。逐 seed 11/22/33 原样重建全部初始矩阵，跨学习率 hash 相同；各 seed 之间的初始化谱未匹配。旧 eta=.02/3000 步的 3 个 cell 只读复用；新增 eta=.005/12000 步与 .00125/48000 步，共 6 个训练 cell，均 eta×步数=60，训练耗时 6.531911 秒。

保存曲线为 MSE=mean(err²)，沿用旧更新 g=2err/n，实际优化 J=4×MSE。没有在本轮纠正梯度，因而配对只改学习率与相应步数。A 保留全部 step 点的自由下平台 log-time logistic 最小二乘；B 保留 11 点原始 step 平滑及 log(1+step) 最大负斜率位置。

| eta | A 形状通过 | A/B 在 0.5–2 内 | A/B 比值范围 | A 时间均值（step） | A 时间 seed CV |
|---|---:|---:|---:|---:|---:|
| 0.02（旧） | 3/3 | 0/3 | 0.053479–0.269599 | 0.925557 | 0.705261 |
| 0.005 | 3/3 | 3/3 | 0.824100–0.868042 | 6.239867 | 0.323635 |
| 0.00125 | 3/3 | 3/3 | 0.779080–1.016098 | 27.745151 | 0.276924 |

P1 要求最细 eta 的 3/3 比值进入 0.5–2，且 |ln(A/B)| 比旧条件减少至少 25%。逐 seed 减少率为 88.768804%、99.454673%、80.955345%，支持 3/3。逐 seed 比值增量为 +0.661969、+0.962619、+0.509481；均值 +0.711357，df=2 的配对 95% t 区间 [0.138588,1.284125]。三个已选初始化不代表 seed 总体。

固定时钟诊断取 tau=eta×step、s=tau/.02。A 对所有点用 log(1+s) 拟合；B 先插值到 tau=.02 的公共网格，再做相同 11 点平滑。这使旧基线完全保留，固定了时间偏置与平滑窗口。

P2 要求 A/B 的两个较小 eta 读数相对差都不超过 10%，故被推翻。reference B 的三个 seed 在全部 eta 均为 tau=.12，即公共网格第 6 点；最细 eta 的 reference A/B 3/3 仍低于 .5。原协议中时间轴的 +1 和 11 点窗口随 eta 改变，故 P1 不单独证明动力学相变的协议无关性；P2 也只检验声明协议的收敛，粗网格 B 的零变化不等于真实峰值已收敛。

## 核验、失败与边界

30 个旧 study 文件 hash 与 mtime 保持不变。新 6 cell 的 72 个 checkpoint 和最初 12 次局部更新通过独立 einsum/高精度求和核验；loss 误差≤2.220446e-16，权重更新误差≤5.551115e-17，拟合 RMSE 重算误差≤8.673617e-19，R² 重算差为 0。18 次原/reference B 峰值位置重算一致。恢复调用新增 0 训练和 0 拟合，21 个成功 NPZ/回执/拟合文件 hash 与 mtime 不变。

首次训练发出 matmul 的 divide-by-zero、overflow、invalid RuntimeWarning，但保存 loss 和全部 checkpoint 权重有限，独立重构通过。根因未定，未删除警告或重训成功 cell。冻结前草稿的 R² 表达式与换行转义错误已通过静态检查修正，当时未训练或拟合。预注册按要求 git add -A，包含已有 supervisor/D4 异步产物；本轮未编写或科学使用它们。

旧 A 合同写 tc>=1，但旧源码实际 h>=0、tc=expm1(h)>=0；本轮明确冻结实际约束，不改旧数据。B 的 final loss 只作为下基线，实际是导数峰值估计，不执行固定平台的另一次 sigmoid 拟合。已知单模式解不保证一般多层随机矩阵链的总 loss 是精确 logistic，本轮不把背景启发当作证明。

只测固定 L4、固定目标/数据、三已选初始化和两新离散 eta。A 是单起点局部最小二乘，不称全局最优；没有标定 d_eff，没有测 skip、宽度、其他 sigma 或目标、其他优化器、test 或无限时间梯度流。
