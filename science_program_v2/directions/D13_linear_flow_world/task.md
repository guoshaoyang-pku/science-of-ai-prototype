# D13 — Linear Flow World：有效深度与相变时间

来源：用户 2026-10-07 群内讨论（亦见 Textbook/Meta Model 线索）；规格图冻结在 `../../sources/linear_flow_world_spec.png`（manifest 有 hash）。论文种子标题（用户给定，作为目标之一）：*Measuring effective depth using phase transition time*。

## 模糊问题

最小的 Architecture IQ 世界：**深度线性网络**（无 ReLU/Normalization/Attention，只有线性层与 skip connection）。只允许改三件事：各层初始化尺度 {σ_l}、skip 拓扑（在哪里加 skip）、各层宽度 {width_l}；其余全部固定。

核心问句（规格图原话）：**Can we understand a deep linear network just from its architecture and initialization?** 即：是否存在一套可计算的指标/理论，从 ({σ_l}, topology, {width_l}) 预测训练动力学与最终性能？

用户的经验观察（待验证/定量化，不是结论）：
1. 训练曲线（loss vs step）大体都能被 sigmoid 拟合；
2. 由此可定义**相变时间** t_c（曲线陡降/中点位置）；
3. **有效深度**与 t_c 一一对应：网络越深，相变越晚；skip 会改变有效深度。

## 已知起点（背景理论，不作为本方向新发现）

- **Saxe et al., arXiv:1312.6120**（Exact solutions to the nonlinear dynamics of learning in deep linear neural networks）：深度线性网络 + 线性目标下，学习曲线精确为 sigmoid 型（奇异模式逐个跃迁）。本方向的设定是它的扩展：加 skip connection、允许各层初始化尺度 {σ_l} 变化；用户猜想仍（近似）sigmoid——这是待验证猜想，不是结论。该 setup 的定位（用户原话要义）：non-trivial 与 tractable 之间的好折中。
- 无 skip 的深度线性网络在梯度流下有精确奇异值动力学（同上）：相变延迟 ∝ 深度 × ln(1/初始化尺度)。这解释了"越深相变越晚"，并给出 t_c 的候选公式。
- 本程序既有资产：D4/D12 的 log-time logistic 拟合器与级联公式（t50、陡度定义可直接复用）；D10 的逐层核求和时间（非线性网，需在线性网重新检验）；D3 的目标加权谱描述量（线性网下目标=线性映射，谱构造更干净）。
- **skip connection 打破乘积结构的精确可解性**：网络函数成为多条路径的叠加，现有精确理论不覆盖。这是本方向的真正缺口。

## 拟合协议（用户补充 2026-10-07 21:00，一等子问题）

t_c 与 d_eff 的数值依赖拟合协议，协议选择必须先受控比较：

- **协议 A（自由拟合）**：对全部步的点做残差最小化拟合 log-time logistic，下边界自由。用户先前在**未简化设置**下用此协议效果不好（失败记录，作为边界证据保留）；在简化设置（线性网+线性目标+全批量）下是否足够好，待测。若足够好，优先用它（用户偏好：更方便）。
- **协议 B（强制约束）**：sigmoid 下边界固定为实测 final loss；相变点取平滑后 loss 曲线上斜率最大处。作为 A 失败时的回退与对照。
- 比较判据（首轮即做）：两协议在各深度/seed 上的 t_c 一致度（配对区间）、t_c 对 seed 的稳健性、与标定律拟合的残差；报告"A 在简化设置下通过率"，并给出 A/B 分歧最大的条件。
- d_eff 的标定映射必须声明所用协议；若两协议 t_c 系统性偏移，d_eff 定义以声明协议为准并记录偏移量。

## 子问题

1. **复现与标定**：无 skip 链上，t_c 对深度 L、初始化尺度 σ、宽度 w、目标谱的依赖；与背景理论公式逐项对照（哪些项对、哪些项偏）。训练曲线用 D4 的 log-time logistic 拟合并报告通过/失败边界。
2. **有效深度的定义与可组合性**：用无 skip 链标定 t_c→d_eff 的单调映射；然后对带 skip 的拓扑读出 d_eff。检验组合律：串联块是否相加？并行路径是否取某种加权最小？residual（恒等 skip）把 d_eff 降到多少？d_eff 是否只依赖拓扑与 {σ_l} 而与宽度弱相关？
3. **容量/性能指标**：除 t_c 外，最终拟合误差与拟合预算能否由一组架构描述量预测（候选：路径和尺度 Σ_paths Πσ_l、最长/最短路径、初始化流图的谱半径、逐层条件数）？在拓扑网格上做受控区分：匹配候选描述量但拓扑不同的配对，看哪个描述量真的预测动力学。
4. **相变的形状**：纯链是单 sigmoid 还是级联（各奇异模式先后跃迁）？skip 是否合并/分裂相变？与 D12 的谱比边界如何对应？

## 什么算进展

- t_c 的标定律（对 L、σ、w 的依赖，带拟合系数与误差），无 skip 情形与背景理论对照。
- d_eff 的第一版操作定义 + 至少两个拓扑组合律的检验（一个成立一个被推翻也算进展）。
- 一个架构描述量在拓扑网格上通过配对区分检验（development），并做一次封存新拓扑的前瞻预测。
- 全部曲线拟合结论附边界（哪些 recipe 单 sigmoid 不够）。

## 首轮建议

最小闭环：深度 L∈{1,2,4,8} 的无 skip 链（宽度固定 32、固定目标线性映射、全批量 GD、float64），每深度 3 seed；保存 loss 曲线。同批曲线同时用协议 A（D4 拟合器，全点残差、下边界自由）与协议 B（下边界=final loss、t_c=平滑曲线最大斜率点）提取 t_c 与陡度；报告：单 sigmoid 通过率、A/B 的 t_c 配对一致度、t_c 对 L 的标度（线性/对数）。一轮内可完成；拓扑实验留到下一轮。
