# D10 — 深度：规律的逐层传播

## 模糊问题

现有规律几乎都测于 1–2 个 hidden 层。深度增加时：有效时间 U、条件数机制（D5）、奇偶通路（D8）、核漂移（D6）如何逐层传播或失效？有没有逐层可测的量能把深层网络的拟合时间分解？

## 已知起点（只读）

- D5：LN 降 Gram 条件数方向 12/12 一致，但与收益幅度相关不足（r=.42<.5），条件数差在初始化已存在。
- D8：单层冻结特征下 bias 的 a²/a⁶ 规律；v1 C01 的奇偶分解在多层会被打破（未测）。
- v1 A02/A03：d3w192 深 recipe 的 offset/LN 效应。主线 K1038：深（≥3 层）zero-LN MLP 的 SGD 表现 task-dependent。
- v1 C handoff 明确把"多层传播"列为未决。

## 子问题

1. 逐层有效时间：把每层的局部 Jacobian 谱当作该层的"λ"，深度网络的拟合时间是否由最慢层主导？还是层间耦合产生新时间尺度？
2. LN 的条件数效应随深度如何累积？D5 的中介失败在深层是否变成成功（层数放大机制差异）？
3. 奇偶混合的逐层传递：输入含 bias/非对称时，第 L 层的偶能量占比有没有递推关系？
4. 深而窄 vs 浅而宽：匹配参数量时，上面哪些规律区分这两种形状？

## 什么算进展

- 一个逐层可测的描述量，在深度 2→6 的受控族上预测拟合时间（development 建立 + 封存新深度前瞻验证一次）。
- LN×深度 的配对测量，回答 D5 未决的中介问题在深层是否变化。
- 失败与反例保留（如某层主导律在某深度断裂）。

## 首轮建议

从子问题 1 入手：固定 width、SiLU/GELU、全批量 SGD，构造深度 1/2/4/6 的族，同一目标函数；逐层保存 Jacobian 谱与层内残差，先做描述性测量（哪层最慢、总时间与最慢层时间的比值），再定预测量。参考 v1 A02 executed 的 MLP 构造代码。
