# D3 — 模型容量与分辨率的描述参量

## 用户指定核心问题（2026-10-07 21:0x，报告必须最先回答，不许跑题）

**训练量 U 超过拟合阈值之后，模型会停在哪里。** 报告"结论"节第一段必须给出停点公式：有限 U 下的残余 = 未移动慢模态尾部和（用精确级数表述），U→∞ 的 plateau 由什么决定（零特征值/不可学分量 + 数值底），带实测验证误差；"哪些标量描述量不够"压缩为一段 support。

## 模糊问题

用什么**可测量**的参量描述：
1. **容量**：一个模型能拟合多复杂的函数；
2. **分辨率**：一个模型能分辨多细的结构（高频/窄特征/相近模式）？

参量要能跨宽度/深度/激活/LN 配置比较，并且能预测拟合行为，而不只是事后描述。

## 已知起点（只读）

- v1 B01–B03（`../../../references/science_program_v1/studies/`）：目标对齐的曲率谱决定固定特征拟合时间；晚期 learned kernel 的目标 Rayleigh 商 1.82–4.73×（B03）；总 trace/标量 U 不足以刻画容量。
- v1 A03：同 width 下 LN 效应 8/8 配对区间<0——width 不是唯一容量轴。
- 主线 K1073：Δ 最优是 recipe/batch 特异的，不存在普适 epoch 阈值——暗示"容量"必须条件化描述。

## 候选描述量（待检验，不是结论）

- 核/Hessian 谱的**有效秩**、谱衰减指数、目标加权谱质量（B03 的 Rayleigh 思路）。
- 分辨率类：能分辨两个相近目标结构所需的最小谱质量差；NTK 高频衰减；width/深度对谱尾部的影响。
- 组合量：如"在预算 T 内可拟合的目标类半径"——把容量定义成可操作预测而不是参数计数。

## 什么算进展

- 至少一个描述量在**多个架构轴**（width、depth、激活、LN）上单调且可测，并在封存新配置上前瞻预测拟合时间/误差（开发→封存 OOD 流程）。
- 一个"分辨率"操作定义：构造成对目标（结构差异可调），测模型区分它们的最小训练预算，检验该预算与谱量的关系。
- 明确参量数（counting）为什么不够的受控反例（如 A03 同 width 不同 LN）。

## 首轮建议

固定特征线性模型上把"谱衰减指数 × 目标对齐"与拟合时间的关系做成可复算的解析+数值基线（B01 框架可复用），定义出第一版描述量，再考虑引入 learned 特征。
