# D4 — 训练曲线的 sigmoid 描述

## 用户指定核心问题（2026-10-07 21:0x，报告必须最先回答，不许跑题）

**拟合什么时候成功、什么时候失败。** 报告"结论"节第一段必须是判定规则清单：成功当且仅当…（谱比阈值、选解目标、α 条件逐条 if-then），失败当且仅当…，每条带实测通过计数；级联公式与数值界压缩到 Formulation/support。

## 模糊问题（用户新提出）

训练曲线（loss vs step）能否用 sigmoid 描述？sigmoid 的各个参数（起点、终点、中点、斜率）是否存在可推导/可预测的公式？

## 形式化建议

候选族（可增补）：
- 时间轴线性：L(t) = L∞ + (L0−L∞)·σ((t₀−t)/τ)，σ 为 logistic。
- 时间轴对数：同上但 t→log t（很多经验损失曲线在对数时间轴上更像单 sigmoid）。
- 双段/级联 sigmoid（grokking 式延迟跃迁：平台 + 骤降）。

要回答：
1. **拟合质量**：什么条件下单 sigmoid 足够（相对残差阈值事先定），什么条件下必须多指数/级联？
2. **参数公式**：t₀、τ、L∞ 能否由已知量预测——固定特征下 B01 的精确模态递推给出多指数和 eᵢ(t)=(1−ηλᵢ)ᵗeᵢ(0)；多指数和何时近似 logistic？中点/斜率与谱（λ 分布、目标对齐）、lr、momentum 启动项的关系？
3. **可预测性**：用曲线前段（如前 30%）拟合的 sigmoid 参数能否外推最低点/终点（与 D2 的早停问题相接）？

## 已知起点（只读）

- v1 B01（`../../../references/science_program_v1/studies/B01_effective_time/`）：固定特征全批量下逐步精确递推已验证（误差<1e−12）；这是 sigmoid 近似的解析对照基线。
- v1 C04：U 型 test 风险 = 信号下降 + 噪声上升两个过程的叠加；train 侧 sigmoid 与 test 侧 U 型的参数应可互相约束。
- 文献常识（不作为新发现）：神经缩放律里常用 logistic/指数族；grokking 延迟跃迁。本方向的价值是**受控小系统里的参数公式与前瞻验证**，不是再拟合一条经验曲线。

## 什么算进展

- 固定特征系统：从谱解析推导"等效 sigmoid 参数"（t₀、τ 关于 {λᵢ, eᵢ(0), η, μ} 的表达式或近似），与数值拟合对照，给出成立范围。
- 小 MLP（learned 特征）：测 sigmoid 拟合质量的边界——哪些 recipe 单 sigmoid 够、哪些不够；不够时级联参数是否仍稳定可测。
- 一次封存前瞻：用前段拟合预测后段（含最低点），报告误差。

## 首轮建议

先在固定特征二次型上做：单模态=纯指数；两模态=双指数和；解析研究双指数和何时像 logistic（时间尺度分离程度作为控制变量），数值验证。这是一轮内可完成的小闭环。
