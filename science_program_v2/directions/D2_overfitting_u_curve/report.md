# D2：风险何时回升、回升后如何增长

## 结论

上升起点的三个分支是沿 σ² 轴的三次留出拟合；系数对 n 的依赖尚未建模，跨 n 散布约为 ±60%，只适用已测格点 n∈{32,64,128}、σ²∈{0.25,0.5,1,2,4}。上升后的短段公式是保存数据事后拟合（development，即已见数据上的拟合）：

\[
\widehat U_{\rm rise}\approx
\begin{cases}
0.214514(n/\sigma^2)^{1.05557},&n=32,\\
0.328362(n/\sigma^2)^{0.96928},&n=64,\\
0.202563(n/\sigma^2)^{1.09019},&n=128,
\end{cases}
\qquad
L_{\rm test}(U)-L_{\min}\approx
C\left(\frac{U-U_{\rm rise}}{U_{\rm rise}}\right)^{1.545565},
\quad 0.1\lesssim\frac{U-U_{\rm rise}}{U_{\rm rise}}\le1.
\]
U=ηt 是累计训练量。η=0.3 是每步学习率。t 是更新步数。
U_rise=ηt* 是实测回升起点。t* 是保存窗口内第一个最低点的步数。帽号表示预测值。
n 是训练样本数。σ² 是归一化训练标签的噪声方差。
L_test 是无噪声审计标签上的期望均方误差。L_min 是它的最低值。
C=L_test(2U_rise)−L_min 是每条曲线在两倍起点处的回升量，单位为标签平方。

上述公式限于四维高斯输入、目标 x₀+0.5x₀x₁、宽度 128 的冻结特征和全批量梯度下降优化平方损失。x₀、x₁ 是独立标准高斯输入坐标。冻结特征指训练时不改变隐藏层。全批量梯度下降指每步使用全部训练样本更新参数。
起点预测只用原训练样本标签归一化扫描检验；后续归一化与降噪曲线只复核上升支描述。

这三个 U_rise 分支是沿 σ² 轴的三次留出拟合，不是已经建立的跨 n 定律。系数的 n 依赖尚未建模，跨 n 的散布约为 ±60%；公式只适用于已测格点 n∈{32,64,128}、σ²∈{0.25,0.5,1,2,4}。

- 起点大致随“样本数除以噪声方差”增加。原 n=32/64/128、σ²=0.25/0.5/1/2/4 的留出样本量预测中，57/60 起点在实测值的两倍内，实测 U_rise 为 2.4–166.5。
- 实测最低点就是首次回升的转折点。全部 78 条保存曲线都在最低点后的下一步升高，之后至第 16384 步没有下降区间，起点的网格分辨率为 0.3。
- 短段回升约按距起点的 1.546 次方增长。保存数据事后拟合（development）在原扫描 54/60 条曲线、其余归一化与降噪条件 17/18 条曲线上，全部取样点均在两倍误差内，C 的范围为 0.00101845–0.119553。
- 这个幂律不能覆盖整条后期上升支。保存数据事后拟合（development）延伸到第 16384 步时，78/78 超过两倍误差，预测回升量为实测的 4.89–2634.75 倍。
- σ²/n 尚不足以给出统一起点系数。在 n32/64、两个相同比值格点128/256、四seed、同一冻结特征协议下，共享分布标签归一化后，起点比例系数的跨n极差由 .0158203125 增到 .0740625；“至少减半”的预测被推翻。这限制单一系数的跨n使用，不撤销原57/60留出预测。
- 不要把这些式子外推到未测协议。学到特征、非线性读出、交叉熵、小批量训练、其他目标或输入维度均未测；上升支的 1.545565 幂律只在 x∈[0.1,1] 的短段内描述。

## Formulation

将已有步数幂律换成累计训练量，有 \(\widehat U_{\rm rise}=\eta e^a(n/\sigma^2)^b\)。留出 n32/64/128 的 (a,b) 仍为 (-0.33541,1.05557)、(0.09033,0.96928)、(-0.39273,1.09019)。系数分别为 0.2145143101、0.3283616599、0.2025632721。a 为以更新步为单位的截距，b 为幂次；这不是三个独立的样本量分段机制，而是三次留出拟合。

保存数据事后拟合（development）的上升支写为 \(L_{\rm test}(U)-L_{\min}\approx Cx^p\)，其中 \(x=(U-U_{\rm rise})/U_{\rm rise}\)，\(p=1.5455654305138984\)。x 是超过最低点的相对训练量，无量纲；C 是该曲线在 x=1 处的实测风险增量。式子只描述 x 约为 0.1–1 的短段。保存曲线的 \(L_{\rm test}(\eta t)=R(t)\)，以下解析式则覆盖已保存的全部整数步。

从固定特征的风险分解可写出 \(R(t;s)=B(t)+sN(t)\)，其中 \(N(t)=\|\Phi_aA_t\|_F^2/m\)，而 \(A_t\) 由训练 Gram 矩阵除以 n 的递推得到。写成 Mₙ(t)=nNₙ(t) 后有 Rₙ(t;s)=Bₙ(t)+(s/n)Mₙ(t)。只有 Mₙ 与 Bₙ 在跨 n 条件下接近，s/n 才足以折叠风险；Aₜ 的显式 1/n 不单独保证这种接近。“噪声拟合速率随 s/n 变化、信号项在谱集中后近似不随 n 变化”是待检验的机制解释；它不替代三次留出拟合，也不把谱量关系当作已测结果。

保存曲线评价的注册定义为 Δ_T(s)=R(T;s)−R(t*(s);s)，其中 T=16384；“操作性 U 型”定义为 0<t*<T 且 Δ_T≥.05。n=32、seed=411 的旧 σ²=.125 与新 σ²=.0625 只改变 s，signal_bias、variance_unit 和全部输入特征保持不变。


固定特征、零初始化线性输出层、全批量 GD 与平方损失下，条件期望风险按以下已知解析式计算。风险递推与 population 矩不作为新发现。

\[
K=\Phi\Phi^\top/n=V\operatorname{diag}(\lambda_j)V^\top,\quad q_j=1-2\eta\lambda_j,\quad
f_j(t)=\begin{cases}(1-q_j^t)/\lambda_j,&\lambda_j\ne0,\\2\eta t,&\lambda_j=0,\end{cases}
\]
\[
A_t=\Phi^\top V\operatorname{diag}(f_j(t))V^\top/n,\quad
R(t)=\|\Phi_a A_t y-y_a\|_2^2/m+\sigma^2\|\Phi_a A_t\|_F^2/m,\quad
t_*=\min\operatorname*{argmin}_{t\in\{0,\ldots,16384\}}R(t).
\]
\[
y^{\rm train}=(g-\mu_n)/s_n,\quad y^{\rm pop}=g/\sqrt{1.25},\quad
g(x)=x_0+0.5x_0x_1,\quad E[g]=0,\quad E[g^2]=1.25.
\]
\[
R(t;s)=B(t)+sN(t),\quad t_*(s)=\min\operatorname*{argmin}_{t\in\{0,\ldots,T\}}R(t;s),
\]
\[
\Delta_T(s)=B(T)-B(t_*(s))+s[N(T)-N(t_*(s))],\quad
U_{.05}(s)=\mathbf 1\{0<t_*(s)<T\;\land\;\Delta_T(s)\ge .05\}.
\]

n 和 m=2048 是训练与风险审计样本数，单位为行。Φ、Φₐ 是含常数 bias（偏置）列的固定特征矩阵。K 是训练 Gram 矩阵（训练特征两两内积除以 n），V 的列为其特征向量，λⱼ 为对应特征值。η=0.3 是学习率，qⱼ 是每步收缩因子，fⱼ(t) 是累计响应，j 是特征模态索引。Aₜ 把训练标签映射为第 t 步输出层参数。y、yₐ 是 clean（无噪声）训练与审计标签。σ² 是归一化标签单位下的独立训练噪声方差。R 的单位为标签平方，t、t* 的单位为更新步。标签与特征无量纲；diag 表示对角矩阵，⊤ 表示转置，‖·‖₂ 是欧氏范数，F 下标表示矩阵所有元素平方和的平方根。

g 是原始目标，x₀、x₁ 是独立标准 Gaussian 输入坐标。μₙ、sₙ 是原始训练目标的均值与中心化均方根（RMS）。train/pop 上标表示训练样本与分布归一化，E 表示分布期望。B(t) 是无噪声 GD 的 clean 审计均方误差（MSE），单位为标签平方。N(t) 是单位训练噪声方差的审计响应，保存数组名为 variance_unit，单位为风险除以标签方差。s=σ² 是噪声方差；T=16384 是窗口终点，单位为更新步。t*(s) 是该方差下首个全局最低点；Δ_T 是终点减最低风险，单位为标签平方。U₍.05₎ 是取 0 或 1 的操作性判据，𝟙 表示条件成立时取 1，0.05 的单位为标签平方。

机制表达为 t*=f(σ²/n；谱)：固定特征分解中的噪声响应含有 1/n 因子，信号项在谱集中后对 n 近似不变；已测范围内的 t* 对 σ²/n 呈近线性趋势，但这不是解析定律。

经验式为 log(t*)=a+b log(n/σ²)。a 是截距，b 是斜率，log 表示自然对数；拟合使用以更新步计的 t* 和归一化标签单位下的 σ²。它是本组条件的经验预测，不是解析定律。



跨 n 机制的已知代数写法为 Rₙ(t;s)=Bₙ(t)+(s/n)Mₙ(t)，Mₙ(t)=nNₙ(t)。相邻步有 ΔRₙ=ΔBₙ+(s/n)ΔMₙ。Δ表示第t+1步减第t步，单位为风险/更新步。若 ΔMₙ>0，则该步风险上升当且仅当 s/n>−ΔBₙ/ΔMₙ。局部上升判定不自动等于全局最低点，公式也不假定Bₙ或Mₙ跨n相同。

保存曲线系数比较的注册定义为 x=n/s、cₙ=.3∑(x t*)/∑x²、D=|c64−c32|；只汇总x=128/256、seed411–414，固定幂次1和零截距。预测判据为D_sample>0、D_population/D_sample∈[0,.5]且全部32最低点内部。c的单位为累计训练量除以样本数/标签噪声方差；该c与上文自由指数留出拟合的系数不同。

## 成立程度

起点公式保留原来“用另两个样本量拟合，再预测留出样本量”的检验口径。每次拟合 40 条曲线，留出 n=32/64/128 各通过 19/20，共 57/60，达到至少 48/60 的原判据。三个失败预测的倍数误差为 2.286/2.099/2.571。实测最低点为 8–555 步，换算成 U 为 2.4–166.5。这里只测了学习率 0.3；乘以学习率是单位换算，没有检验换学习率后是否仍重合。

上升支公式是保存数据事后拟合（development）。指数 1.5455654305138984 由原 60 条曲线共同拟合。原 15 个实验条件各有四个随机种子重复；54/60 的通过率是拟合内描述。其余 18 条曲线通过 17/18；它们共享部分输入和特征，是已见条件上的复核，不是事前封存的分布外验证。

每条曲线的 C 都使用该曲线自身的已知风险。判据要求距最低点约 0.1–1 倍最低点步数内的全部几何间隔取样点都在两倍误差内；整数取样有至多 0.5 步的取整差。逐曲线单独拟合的指数为 0.919789–1.886455；共同指数的最大倍数误差为 3.077841。不能把共同指数当作每个条件都成立的精确指数，也不能把取样点通过解释为区间内每一步都通过。

尾部验证没有重新拟合。78/78 条曲线在第 16384 步都未通过两倍误差判据；该时刻 U=4915.2。报告没有测出覆盖整个上升支的单一增长指数。需要整条风险时，应使用固定特征的已知解析递推，而不是外推短段幂律。

所有结果为 development。最低点和 C 都依赖无噪声训练/审计标签；它们不是只用训练标签的早停信号。没有检验参与训练的隐藏层、Adam 自适应优化器、小批量训练、交叉熵损失、其他宽度或无限训练。

## 方法与条件

在 n=32、seed=411 的同一 population 曲线上把 σ² 从 .125 降到 .0625，最低点从 331 步移到 528 步，终点减最低风险从 .1773813165 降到 .0820704085；内部最低点和 .05 回升幅度仍保留。该结果支持本次注册的有限区间，不能扩展为跨 seed 规律。

事后拟合只读取五组已完成研究的 78 条风险曲线，不组合新噪声条件。每条曲线取偏移步数 round(geomspace(max(1,0.1t*),t*,40))，去重后在对数坐标拟合；geomspace 指按固定倍数递增取样。C 锚定该曲线在两倍最低点步数处的回升量。原 60 条曲线共同最小化对数误差平方和，再固定指数复核其余 18 条曲线。首次探索曾使用逐曲线指数的平均值 1.547336137459214；正式汇总按合并取样点最小二乘得到 1.5455654305138984，没有搜索模型或改窗口。

共享 population 标签归一化（按分布均值与均方根归一化）未消除 seed414 反例。其比值由 2.8125 变为 3.24194，满足事前区间 (2,4]；标签归一化差异不足以单独解释反例。四个种子仍只有 3/4 配对在两倍内，比值范围 1.00543–3.24194，log₂ 范围 0.0078195–1.6968554；归一化干预对 log₂ 比值的改变量范围为 −0.1190926–1.0780025。8 个最低点为 62–201 步，全部满足内部最低点且终点回升至少 0.05 的原操作性 U 型判据。

### 失败与反例

短段共同幂律在七条保存曲线上失败。原扫描失败条件为 n32/seed411/σ²0.5、n32/seed413/σ²2、n32/seed413/σ²4、n32/seed414/σ²4、n64/seed411/σ²4、n128/seed413/σ²4；共享分布归一化中 n32/seed411/σ²0.25 也失败。最大倍数误差分别为 2.784528、3.077841、2.041362、2.315551、2.370309、2.356628、2.006392。失败条件没有排除。

短段幂律延伸到终点的回升预测全部偏高。原扫描为实测的 4.890795–2634.745466 倍，共享分布归一化为 29.541671–133.263526 倍，噪声减半为 12.613862–67.674343 倍，更低噪声 seed412/413 分别为 38.674616/18.916244 倍。这个失败只否定该幂律的尾部外推，不否定已保存风险曲线或固定特征解析递推。

本轮 n32/seed411 的单一配对评价给出 t*=528、最低风险 .12486673374136117、终点风险 .2069371422480195、Δ_T=.08207040850665834；注册区间 [.05,.15] 支持。相同曲线的 σ²=.125 基线为 t*=331、最低风险 .16812179640849967、终点风险 .3455031129056644、Δ_T=.1773813164971647。


“全部折叠”的预测被四个反例推翻。seed414 在 n32/0.25、n64/0.5、n128/1 时 t* 为 64、180、176 步；seed412 在 n64/0.25 与 n128/0.5 时为 390、160 步；seed413 在 n64/2 与 n128/4 时为 20、47 步。前两个反例共享 n32 结果，不是独立重复。

幂律仍有三个失败预测，倍数误差为 2.286/2.099/2.571。斜率 b 为 1.05557/0.96928/1.09019。零反例的严格折叠与容许 20% 失败的粗略预测可以分别失败与通过，不能用 57/60 的通过结果撤销 40/44 的失败结果。

共享归一化和降噪后，seed414 仍超过两倍。共享归一化使其比值从 2.8125 变为 3.24194；随后噪声减半使最低点从 62/201 步变为 87/324 步，跨 n 比值从 3.241935 变为 3.724138。不同条件的最低点延后幅度仍不同。输入抽样、经验谱与目标在特征上的投影仍是竞争解释。

“降噪后仍达到 0.05”在 n32、seed412、σ²=0.0625 的有限窗口条件不成立：终点差值 0.022152202，阈值余量为 −0.027847798。该条件仍有内部最低点和风险回升。事前预测的是阈值未通过，且得到支持；这不是事前区间预测失败。噪声减弱使终点风险比最低风险下降更多，原操作性 U 型判据失效只说明回升幅度未达到阈值。

seed413 的差值区间 [0.015,0.045] 被推翻。实测 0.014188114079254938 低于下界；不能因同一预测中“低于 0.05”的方向符合结果，就把整个 P1 写成支持。原 .05 操作性 U 型判据同样失败，保留内部最低点与正回升。

seed411 的同协议评价与 seed412/413 不同：σ² 减半后 Δ_T=.0820704085，仍高于 .05；t* 比值为 528/331=1.5951661631，Δ_T 改变量为 −.0953109080。四个 seed 的低噪声结果仍只构成四个有界 development 配对，不能估计跨 seed 概率或连续临界值。

执行失败保留为执行失败，不算科学反驳。原执行因预注册提交受阻而未训练，随后恢复；噪声减半准备因临时脚本写出工作区而失效，没有新实测数字或 KB claim（知识库短结论），也没有执行独立实际 GD。原 matmul（矩阵乘法）警告的底层原因未定。归一化分析曾因 NumPy 布尔值不能直接写 JSON 而失败；固定源码和原错误保留，单独入口只把 NumPy scalar（标量）转为 Python scalar，未改风险公式或预测。

“标签归一化后跨n系数极差至少减半”的预测在注册两格点上失败。协调者已保存的另一个散布量、或排除seed414后改善，均不能替代主判据。不得将剩余反例直接归因为有限n谱；输入、目标投影、谱与审计对齐仍未分别控制。

## 未决问题

短段幂律尚不能由 n、噪声方差和训练侧量独立预测系数 C。整个上升支的增长公式也未建立；尾部需要饱和项或完整的固定特征响应，现有数据没有给出前瞻验证。


输入抽样、目标投影与经验谱的独立作用尚未区分。共享标签归一化与噪声减半后仍有反例，现有对照不足以独立归因。

四个指定 seed 的低噪声评价仍不给跨 seed 概率或连续噪声临界值。σ²=.0625 的新低噪声重加权实际只保存了 seed411/412/413 三个评价；四 seed 指 .125/.25 的原减半配对，不能把它写成四个 .0625 结果。下一小问题优先先审计本轮提交与来源不可变性，再在保存的 population 曲线上检验噪声响应与 σ²/n 机制量；若继续做新条件，必须先注册具体数值区间、来源 hash 与 pinned 源码，且不先组合新端点后称盲预测。

后续机制检验可仅替换保存曲线中的M项，固定population seed414、x=256、n64的B，检验与n32起点237步差是否缩小至少一半。该代数反事实需新预注册，不等于实际训练或谱因果干预。
