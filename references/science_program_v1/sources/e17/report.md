# 目标均值翻转的区分实验：初始残差与可训练 hidden

**e16 的翻转可以被初始输出平移消除。**当标签均值从 0 改到 ±3，同时给初始化输出 bias 加上同样的 ±3，三个函数都恢复为 Adam 赢，配对种子全部一致；每个优化器相对均值 0 的终点 MSE 最大变化仅约 1.01e-5。另一方面，冻结 hidden 只训练线性 head 后，SGD 的误差随均值重新满足凸性；这支持将 e16 的非凸收益归因到可训练 hidden 带来的非线性路径。

关联 K1199；承接 R613055ebce@44b021dec5f5349960da03162810a50493d192b4。发起轮次 e17，job Jfab91d105641。本轮没有 solver 评测，也没有读取最终 benchmark test。

## 1. 预注册与实现

沿用 e16 的三个函数、seeds 0–9 和原精确配置：默认 plain MLP，8D、d3w192、GELU、LN010；plain MSE、SGD .001/m0 对 coupled Adam 3e-5/(.9,.999)，wd1e-4，T256/b64。标签仍按 train 均值平移到 μ=−3、0、+3。另做两种干预：

| 干预 | 唯一改动 | 读取结果前的预测 |
|---|---|---|
|matched_bias|构造模型后、构造优化器前，给输出 bias 加 μ；随后全部参数照常训练。|移除大的初始均值残差后，±3 的 SGD 中心化误差优势衰减，恢复向 μ=0 的 Adam 偏好。|
|frozen_hidden|保留原初始化；hidden 全部 requires_grad=False，只更新最后线性 head。|SGD 的 [L(−3)+L(+3)]/2−L(0) 不应为负，配对终点输出对 μ 应为仿射。|

预注册 SHA256 为 ab2811577fc7b99badbb28cd26d76bec0d07cc29a5dd73aa2ac949765f1edf6d；冻结 commit 为 5313a60ea2ef287d3c14d858e7cea6bceee35af6。原工具暂未提供初始化 bias/frozen hidden 选项，因此本轮使用**显式本地研究执行器**：复制 e16 的内容寻址 model/optimizer/loss/train 快照，只在模型创建位置插入上述干预，另存执行源码 hash。不是忽略字段后声称已执行干预。

共 360 次新训练，约 59.7 秒，无收费模型调用。全部有限成功；109 个终点 MSE 超过 benchmark cutoff=2，保留为研究结果，不作失败筛选。初始化非 bias 参数、输入与完整 minibatch stream 逐项匹配 e16；matched_bias 初始预测的平移、frozen_hidden 位移严格为零均已核验。

## 2. 平移初始化输出后，均值效应几乎消失

Δ=SGD test MSE−Adam test MSE，正数为 Adam 赢。e16 原初始化的 ±3 条件中全部为负；本轮恢复为正。均值 0 条件逐 seed 复现 e16 保存值，差异仅来自统计时 double 重算。区间为固定函数/划分下 10 个配对种子的 t9 95% 区间，未多重校正。

| 函数 | matched_bias μ=−3 的 Δ | μ=0 的 Δ [95% 区间] | μ=+3 的 Δ | 相对 μ=0 的 MSE 最大逐 seed 变化 |
|---|---:|---:|---:|---:|
|02036a|+.999817|+.999815 [.965011,1.034620]|+.999813|1.01e-5|
|071e42|+.596388|+.596387 [.503059,.689714]|+.596385|8.68e-6|
|0852dd|+.578666|+.578667 [.510947,.646386]|+.578667|4.71e-6|

三个函数×两个非零均值的六个预注册赢家方向全部符合；每方向 10/10 配对种子。它说明此 recipe 的强均值效应依赖初始输出与目标的均值错配；**目标的绝对均值本身不是不依赖初始化的规律。**

## 3. 冻结 hidden 后，固定特征预测恢复

冻结 hidden 的 SGD 中，三个函数的对称 chord gap 为正，每个 seed 都满足非负预测。终点预测的仿射第二差 f(−3)+f(+3)−2f(0) 最大绝对值约 1.08e-6，与 float32 舍入相容。

| 函数 | SGD chord gap [95% 区间] | 负值 seeds | 最大仿射第二差 |
|---|---:|---:|---:|
|02036a|+.5290 [.4121,.6459]|0/10|1.08e-6|
|071e42|+.5321 [.4128,.6514]|0/10|8.18e-7|
|0852dd|+.5310 [.4133,.6488]|0/10|1.04e-6|

冻结 hidden 后两者的形状拟合都很弱，μ=0 时 SGD 仅小幅领先；μ=±3 时 tiny Adam 多数仍未拟合常数，测试 MSE 约 9.5–10.5，而 SGD 约 1.9–2.5。这里的巨大总 loss 差主要是常数残差，和 e16 的“双方已拟合均值、形状误差决定胜负”不同，不能把二者合并成同一 optimizer 优势。全数 109 个 cutoff 超限都来自 frozen_hidden 条件。

## 4. 一个可外推的原理与局部机制

对输出最后有可加 bias 的模型，把 y 改为 y+μ，同时把初始输出 bias 改为 b0+μ，会保持全部初始残差不变。在 plain MSE 下，如果 bias 不参与 decay，后续残差和梯度也保持不变，SGD 和 Adam 的训练路径应逐步平移等价。这是代数对称，适用范围比当前三个函数更广，不需要拟合一个目标均值阈值。

本轮仍保留 coupled wd1e-4，bias 参与 decay，因而**没有宣称精确平移不变**：额外 decay 梯度为 wd×μ。在此短预算和弱 decay 下，观测接近不变，但更大 decay/长预算可打破近似。若有 clipping、非平移对称损失、输出激活或额外正则，上述原理需要重审。

综合 e16 与 e17，支持的局部链条是：大初始常数残差提高原 SGD 的数据梯度，改变 hidden/head 联合优化；非线性训练路径使去均值后的目标也更快被拟合。matched_bias 消除启动残差，收益消失；frozen_hidden 消除 hidden 非线性更新，凸性恢复。它仍未确定 LN、具体 feature/Jacobian 漂移、head 幅度增长各自的贡献，也未用公式预测新宽度、lr、budget 下的临界翻转。冻结实验是机制证据，并非所有 kernel 方法的否定。
