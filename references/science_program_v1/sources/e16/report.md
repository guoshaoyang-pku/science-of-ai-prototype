# 改变标签均值，能否因果地翻转 SGD 与 Adam？

**已测得：固定函数、数据划分、初始化和 minibatch，只把标签均值改为 0 或 ±3，就能翻转优化器赢家。**三个函数的 9 个预注册干预方向全部正确，每个方向的 10 个配对种子一致。更强的现象是：SGD 在 ±3 下连去掉均值后的拟合误差也更低；它的优势不能用终点残留均值误差解释。以下给出局部动力学解释和一个被数据否定的简单模型，尚未得到完整的终点预测理论。

关联 KB：K1199；前序报告：R2c901e60c2、Rbf2de3388f。发起轮次 e16，job Jfc41e23dc91c。科学实验未进行新的 solver 评测，因此没有新增 gpt-6.1-sol 涨分结论。

## 1. 把相关性变成可检验的干预

前序报告按表达式估计总体均值，用阈值 |均值|>2.13335 预测 SGD，否则预测 Adam；4 个新函数预测正确。但函数形状、均值、数据划分一起变化，不能确定均值是否有因果作用。

本轮冻结三个此前已观测的 8D 函数：mvar_02036a、mvar_071e42、mvar_0852dd。它们是允许使用的训练实验库中按 ID 排序选定的前三个 8D 数据集，没有按 loss 筛选。对每个函数保留原标签，再构造三个干预：

```text
y_mu = y - mean(y_train) + mu，mu ∈ {-3, 0, +3}
```

同一平移用于 train 和实例内部 test，中心值只由 train 计算；原文件不变。原始训练均值分别为 1.62259、2.71036、-4.67534，区别于前序报告的表达式总体均值。输入、划分、标签的中心化形状不变；浮点平移存在约 1e-7 舍入差异。

在读取结果前，preregistration.json 已锁定“均值 0 时 Adam 赢，±3 时 SGD 赢”。预注册 SHA256 为 d5fdb7ffba75f17272a5e3ee1b4552e551163ff4a9bb04be8ffa8449ba9b6acc；预注册 Git commit 为 67a949a276e40d4de8c8c674a9a73cbc78d32fbc。9 个新干预方向属于三个函数内部的相关检验，不能算成 9 个独立抽取的新函数。

## 2. 精确配置与证据核对

统一输入 U([0,1]^8)，每实例 train/test 各 256 点。网络为默认初始化、无 residual 的 MLP，depth=3、width=192、GELU、LN010；depth 是三层 hidden block，另有输入 projection 和输出 head。比较 plain SGD(lr=.001,momentum=0) 与 coupled Adam(lr=3e-5,betas=.9/.999)，两者 wd=1e-4，plain MSE，256 steps，batch=64，放回抽样。此处学习率不同，结论仅涉及这两个固定 recipe。

共 3 函数×4 条件×2 优化器×10 seeds=240 次训练。记录 step0 和 steps 1/8/32/128/256 的 train/test loss、输出均值、数据梯度、实际更新、head/hidden 位移，以及初始/最终预测。24 cells 全部成功，终点均未超过 benchmark MSE cutoff=2；研究采用 1e12 有限检查以保存诊断，未更改 benchmark 打分。训练请求执行合计约 40.7 秒，本轮无收费模型调用。

analyze_results.py 核对了 582 个唯一证据文件的 SHA256、每个 10×256 曲线及终点、变换 runner 源码、标签 hash；30 个“函数×seed”组的初始化、输入和完整 minibatch stream 在全部条件与优化器间一致。原条件结果与前序报告均值逐项一致；原条件是过程复现参考，不计为新预测。没有读取最终 KB benchmark test。实例内部 test.pt 用于受控训练的评价。

## 4. 优势主要发生在形状拟合

对每个 seed 的测试残差 r=f−y，使用精确分解 MSE=mean(r)^2+mean((r−mean(r))^2)。前项表示全局偏移误差，后项表示去掉平均偏移后的误差。以下为三个关键条件的配对平均差。

全部 12 条件中，偏移误差对总差值的贡献绝对值最多约 5.3%。因此“SGD 终点更好只是因为常数没拟合完”的解释与结果不符。SGD 自身在 ±3 下比 μ=0 下的中心化误差低 .54–.76，Adam 则变高 .15–.67；同样的中心化目标，训练路径已改变。训练 MSE 的优劣也同步变化，不能把现象只归为泛化差异。

## 5. 一个局部原理，以及被否定的简单模型

令中心化目标为 z、标签为 z+μ，初始化 minibatch 的输出 Jacobian 为 J_b。平方损失的梯度满足精确恒等式：

```text
g_mu(theta0) = g_0(theta0) - 2 mu mean_b(J_b)
```

SGD 的第一步响应与 μ 成线性关系；Adam 第一步近似按梯度符号更新，幅度受 lr/epsilon 控制，不能把同样的梯度放大直接当成同样的更新放大。观测中，μ=0 时 SGD hidden 第一更新范数为 .00098–.00138，±3 时升至 .0132–.0141；Adam 在这些条件都约 .01010。SGD 的 head 第一更新也从约 .00062–.00085 升至 .0098–.0104。这给出了偏移如何改变早期训练速度的具体入口。

kernel_diagnostic.py 在原初始化和第一 minibatch 上测量 q_test=J_test mean_b(J_b)，核对了全部 90 个“函数×seed×μ”第一步梯度范数。q 的中心化 RMS/|均值|约 5.0–5.1%，非零：常数目标方向对输出形状也有局部耦合。但这个初始导数不能预测 256 步后的胜负。

进一步可排除一个过于简单的解释。若采用固定特征、固定 Jacobian 的线性模型，保留配对初始化、SGD、相同 minibatch 序列和 coupled L2，则有限步终点输出是 μ 的仿射函数，测试 MSE 必然是 μ 的凸二次函数，必须满足 [L(−3)+L(+3)]/2−L(0)≥0。实测 SGD 的这个值分别为 −.7280、−.5687、−.5569，三个函数全部 10 个 seeds 都为负；对中心化误差同样违反。故固定 Jacobian 的 SGD 动力学无法解释这些终点，必须允许参数化带来的非线性训练路径。数据尚未区分特征变化、Jacobian 漂移、LN 几何和输出 head 的具体作用。该理论检验属于结果后的分析，不属于预注册预测。

## 6. 当前边界与下一项可区分预测

因果结论限于三个固定函数和此精确 recipe。尚未定位 ±3 与 0 之间的翻转阈值；2.13335 仍只是前序拟合阈值，不能写成已测得的物理常数。正负 μ 的收益也不完全对称，例如 02036a 的 −3 与 +3 差值为 −.3695 与 −.2378。仅用 |μ| 不足以预测效应大小。

可继续区分三条解释。若主要由“初始输出均值与目标均值不匹配”启动，应在平移标签的同时平移初始输出 bias，移除大的初始均值残差后，SGD 的优势衰减。若终点来自 nonlinear feature learning，冻结 hidden/固定 Jacobian 的 SGD 应恢复前述凸性，优势不应保持。若只是等效进度校准，匹配实测早期 function update 后应缩小差异；匹配参数总位移并不充分，因为 Adam 的 hidden 总位移更大却仍在 ±3 下输。以上均尚未执行，保留为相互区分的下一项研究。
