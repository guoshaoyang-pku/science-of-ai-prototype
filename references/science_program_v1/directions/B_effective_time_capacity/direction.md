# B：有效学习时间、拟合饱和与容量

当前 KB 的 Δ 是用任务平均梯度校准的进度经验量；它没有测量实际函数变化，也没有给出进入容量比较的统一阈值。本方向先把可精确验证的部分分离出来，再检查非线性网络中何时失效。

## 候选理论

固定特征、全批量、半均方损失 L=||Xθ−y||²/(2n) 时，H=XᵀX/n。普通 SGD 第 i 个可拟合模态的残差为 eᵢ(t)=(1−ηλᵢ)ᵗeᵢ(0)。有效时间应包含目标对齐的曲率谱，不能只用 ηt。小步长下，给定误差阈值 ε，慢模态需要 ηλᵢt≈log(|eᵢ(0)|/ε)；没有与模型和目标无关的充分拟合 U。

PyTorch 动量 SGD（无 dampening、无 Nesterov）满足 eᵢ(t+1)=(1+μ−ηλᵢ)eᵢ(t)−μeᵢ(t−1)，第一步 eᵢ(1)=(1−ηλᵢ)eᵢ(0)。只有慢变梯度、过了启动期且保持稳定时，η/(1−μ) 才是低曲率近似。恒定梯度下累计位移系数是 Uₜ=η[t/(1−μ)−μ(1−μᵗ)/(1−μ)²]；这仍不是所有模态共享的真实函数时间。

Adam 的预条件器逐坐标、随轨迹变化。SGD 的“|g|≈.01”经验换算不构成精确 Adam 等效时间；参数坐标旋转保持固定特征函数问题不变，却可以改变 Adam 的路径。先用这一可区分对照检验 scalar U 的适用边界。

## 竞争解释与首轮实验

|解释|区分预测|B01 测量|
|---|---|---|
|ηt 或 ηt/(1−μ) 足够|同名义 U 的损失轨迹重合|改变 Hessian 谱及目标在快/慢模态的权重，保留谱和初始损失|
|目标加权谱决定拟合时间|完整谱递推预测每步损失；同谱不同目标仍有不同饱和时间|全轨迹与 exact recurrence 比较，保留未达到阈值的右删失|
|固定 Adam/SGD 换算足够|同一个函数问题更换参数正交坐标后换算不变|SGD/Adam 分别比较对角坐标与正交旋转坐标|

B01 是解析校准，不把已知二次优化关系当新科学发现。开发域为 8 维两组谱；在运行前封存 16 维新谱、目标对齐及坐标旋转条件。预测 SGD 旋转不变、谱递推精确，预测 Adam 并非旋转不变；Adam 差异幅度不事后指定。

## 第二轮与外推

B02 从 B01 的失败条件出发：同一 MLP 初始化的函数 Jacobian 给出线性化损失预测，比较动量 SGD、普通 SGD、Adam 及不同宽度。测量 train/test 轨迹、函数变化与初始 Jacobian 的可拟合谱；匹配初始谱预测的进度后若曲线仍不同，说明容量不只是时间重标度。先在两种函数上开发，再封存新函数结构/输入维度/宽度条件与预测。与 C 的激活/U 型研究共享结论，B 不重复其独立实验。

## 报告与边界

每个模型/函数/recipe 是一个单位；seeds 只测条件内稳健性。训练前保存预测和源码 hash，成功结果不可覆盖；恢复先核对 config 与 source pin。报告区分解析基准、观测支持、预测失败和 OOD 结果。充分拟合阈值必须注明误差标准和谱/目标，固定特征结果不自动外推到特征学习，更不登记为 solver 涨分。
