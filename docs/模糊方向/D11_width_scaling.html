D11：宽度与样本量的标度律

结论

已测的预算标度依赖谱尺度。同 Rayleigh 商（目标加权的平均特征值）不能独立决定预算，维数增加也没有消除两目标的预算差。

以下测量均限于结构化固定特征：d=8–8192 的 11 个二倍网格、零初始化、全批量半平方损失 SGD（用全部样本的梯度更新参数）、学习率 η=0.5、无动量、无权重衰减。d 是固定特征参数数，不是真实网络宽度。预算 T 是首次达到相对损失阈值的更新步数。中间目标把能量放在中间谱模态（特征值对应的方向）；首尾目标把能量分配到最快与最慢模态。n 是损失记账使用的样本数。

  • 原谱 λᵢ=i⁻¹（λᵢ 是第 i 个特征值）下，1% 损失预算在已测网格内接近 d 的一次幂。n=d 与 n=8192 零填充条件的结果相同。中间目标拟合为 2.249735 d^1.003161，最大相对拟合误差 0.868262%；首尾目标拟合为 4.438350 d^1.005095，最大相对拟合误差 2.528432%。
  • 同 Rayleigh 商不足以决定预算。原谱下，两目标的该平均值均为 2/d，初始损失均为 0.5；33 个同坐标配对的首尾/中间预算比为 1.944444–2.000000。单 Rayleigh 的单指数近似对首尾目标低估 48.571429%–50.000000%，对中间目标全部准确。维数增加没有消除反例。
  • 固定 n 的零填充对照排除了预算依赖 n=d 损失记账的解释。把 n=d 改为 n=8192，按 √n 缩放前 d 个非零输入与目标，其余样本置零，66 个新旧预算配对的差均为 0 步。归一化损失曲线最大差≤4.440892e−16。非零样本数仍为 d，没有增加独立信息样本。
  • 原近一次 d 标度依赖谱的整体尺度。固定 n=8192，仅把非零谱除以调和和 h_d（从 1 到 d 的倒数之和），使 trace=1（特征值总和为 1）后，1% 预算按 d h_d 的两个已知系数缩放。中间/首尾全网格最大系数误差为 2.126802%/4.124214%。同 Rayleigh 的 33 个预算比仍为 1.959184–1.999956；首尾单 Rayleigh 预测仍低估 48.958333%–49.998894%。
  • trace=1 下，2% 和 5% 两个离散阈值均满足原注册误差边界。2% 的中间/首尾全网格最大误差为 1.244504%/4.771486%；5% 为 1.743710%/4.814219%。两次评价只读取保存曲线，没有改变固定特征或参数更新。这三个已测阈值不能支持连续阈值外推。
  • 同 Rayleigh 的预算差不依赖原首尾目标中随 d 消失的快模态权重。固定上述 trace=1 谱，仅把目标改为 d/4 与 d 模态各占 1/3、2/3 能量后，33 个同坐标配对的 1% 预算是中间目标的 1.823860–1.857143 倍。单 Rayleigh 预测低估 45.171233%–46.153846%。两个占用模态均随 d 缩放，权重保持固定；这仍是固定特征结果。

Formulation

固定特征、零初始化、全批量半平方损失 SGD 的谱递推是已知结果。经验幂律来自网格内拟合；trace=1 的近似系数来自已知谱递推，不是新理论。

\[ L_t=\frac{\|X\theta_t-y\|^2}{2n},\quad H=XX^\top/n,\quad \frac{L_t}{L_0}=\sum_iw_i(1-\eta\lambda_i)^{2t},\quad T_\varepsilon=\min\{t\in\mathbb N_0:L_t/L_0\le\varepsilon\}. \] \[ \lambda_i=i^{-1}\ (i\le d),\quad n\in\{d,8192\},\quad m_1=\sum_iw_i\lambda_i=2/d,\quad w_i=\begin{cases}\mathbf1_{i=d/2}&\text{中间目标},\\ \frac1{d-1}\mathbf1_{i=1}+\frac{d-2}{d-1}\mathbf1_{i=d}&\text{首尾目标},\end{cases} \quad T_R=\left\lceil\frac{\log\varepsilon}{2\log(1-\eta m_1)}\right\rceil. \] \[ \widehat T_{1\%}(d)=\begin{cases} 2.249735\,d^{1.003161}&\text{中间目标；最大相对拟合误差 }0.868262\%,\\ 4.438350\,d^{1.005095}&\text{首尾目标；最大相对拟合误差 }2.528432\%. \end{cases} \]

固定 n 的零填充构造为： \[ X_{i,\pi(i)}=\sqrt{n\lambda_i}\,s_i,\quad y_i=\sqrt{nw_i}\quad(i\le d),\qquad X_{i,:}=0,\ y_i=0\quad(d<i\le n). \] \[ X^\top X/n=P^\top\operatorname{diag}(\lambda_1,\ldots,\lambda_d)P,\qquad \Delta T=T_{1\%}^{n=8192}-T_{1\%}^{n=d}=0\quad\text{（66 个实测配对）}. \] 固定 n=8192、仅整体归一化非零谱后，公式为： \[ h_d=\sum_{i=1}^d\frac1i,\quad \lambda_i^{\rm tr}=\frac1{i h_d},\quad \operatorname{tr}H=1,\quad m_1^{\rm tr}=\frac2{d h_d},\qquad \widehat T_{1\%}^{\rm tr}=\begin{cases} \frac{\log100}{2}\,d h_d=2.302585\,d h_d&\text{中间目标；最大系数误差 }2.126802\%,\\ \log100\,d h_d=4.605170\,d h_d&\text{首尾目标；最大系数误差 }4.124214\%. \end{cases} \]

n 是样本数，d 是固定特征参数数，i 是从 1 开始的谱索引。X 是 n×d 特征矩阵，θₜ 是第 t 步参数，y 是目标。H=XXᵀ/n 是归一化样本 Gram 矩阵（样本特征内积组成的矩阵），λᵢ 是其特征值。wᵢ 是对应目标能量比例，总和为 1。

m₁ 是目标 Rayleigh 商，η 是学习率，ε 是相对损失阈值。Lₜ 是每样本半平方损失，L₀=0.5。特征、目标、λ、w、m₁、η、ε 均采用无量纲数值。t、T、T_R、Ť 的单位是更新步；ℕ₀ 是非负整数，𝟙 是指示函数，ceil 表示上取整。

T_R 是单 Rayleigh 的单指数预算近似。Ť 是在双对数坐标上、按各维数等权拟合的预算。经验系数的单位是步/d^β，β 是无量纲指数。拟合误差为 max_d|Ť/T−1|，不是概率置信区间。

π 是样本模态到参数坐标的置换，sᵢ∈{−1,1} 是坐标符号，P 是对应置换矩阵。后 n−d 个零模态的目标权重为零。ΔT 是同 d、同 seed（置换与符号的随机种子）、同目标的新旧记账预算差，单位是更新步。

h_d 是无量纲调和和，λᵢᵗʳ 是 trace=1 条件的特征值，m₁ᵗʳ 是其目标 Rayleigh 商，Ťᵗʳ 的单位是步。系数误差为 |T/Ťᵗʳ−1|，与拟合误差 |Ť/T−1| 使用不同分母。

两目标的渐近差异可由已知递推解释。中间目标只占用 λ=2/d 的模态。首尾目标在 λ=1/d 的最慢模态上保留 (d−2)/(d−1) 的能量，只用少量最快模态能量匹配 m₁。两预算的渐近斜率均为 1，渐近系数分别为 log(100)/2 和 log(100)。实测指数与约两倍预算比符合这一解释；这不是新谱理论。参数目标范数平方分别为 d/2 和 d−1，二阶谱矩（目标加权的特征值平方均值）也不同，不能独立归因于慢模态质量。

固定权重的新目标记为 q（quarter_tail，四分之一位置与尾部的两个模态）： \[ w_i^q=\tfrac13\mathbf1_{i=d/4}+\tfrac23\mathbf1_{i=d},\quad m_1^q=\frac2{d h_d}=m_1^{\rm middle},\quad m_2^q=\frac6{d^2h_d^2},\quad \|\theta_*^q\|^2=\frac34d h_d. \] \[ \frac{L_t^q}{L_0^q}=\frac13\left(1-\frac2{d h_d}\right)^{2t} +\frac23\left(1-\frac1{2d h_d}\right)^{2t},\quad \frac13 e^{-4C_q}+\frac23 e^{-C_q}=0.01,\quad C_q=4.199706765. \]

q 是目标标签，θ* 是能精确拟合目标的参数；其范数平方采用无量纲数值。m₂ 是目标加权的特征值平方均值。C_q 是从已知递推取 d 增大极限后的无量纲系数，T≈C_q d h_d 的单位仍为更新步。该根在注册后计算，只作解析解释。它不是新理论、拟合参数或注册判据。中间目标的 m₂=4/(d²h_d²)、参数目标范数平方=d h_d/2；这两个量没有与 q 匹配。

成立程度

原谱结果只在 d=8–8192 的 11 个二倍网格内成立。n=d 或 n=8192 零填充、λᵢ=i⁻¹、η=0.5、无动量、无衰减、ε=0.01 时，两条幂律误差均≤2.528432%。完整目标加权谱对 66 个 cell（一个条件与一个坐标 seed 的运行）的整数阈值全部预测正确。66 个样本记账配对的 ΔT 全为 0，差范围为 [0,0] 步。d≥256 的同 Rayleigh 预算比为 1.998302–2.000000。

固定 trace 没有保留旧 d 幂律的误差边界。中间/首尾预算变为 49–180859 步与 96–361710 步，相对原谱分别增加 2.722222–9.588538 倍与 2.742857–9.588326 倍。新预算对 d 的描述性拟合误差为 15.540384%/16.570413%，超出旧误差 6% 边界。

这些结果没有识别独立数据量或真实可学习网络宽度的阈值。固定特征没有核漂移（训练期间特征内积结构的变化），不能识别 lazy↔rich 边界（特征近似固定与特征学习改变动力学的分界）。跨 d 的谱尾、trace 与目标索引共同按规则延伸。随机特征集中、固定输入维度、真实网络宽度及网格外维数均未测试。三个 seed 只改变参数坐标，不是独立数据重复，不计算 seed 置信区间。封存前瞻（未看结果前锁定新条件与预测的验证）尚未执行。

固定权重 q 的对照通过全部注册判据。11 个维数条件×3 个坐标 seed=33 个新训练 cell，无删失；33/33 新/中间预算比在事前 [1.75,1.90] 内，33/33 单 Rayleigh 低估≥40%。同坐标配对的 Rayleigh 与初始损失最大差分别为 6.938894e−18、1.110223e−16。11 组整数预算均在三个 seed 间一致。预算范围为 91–329872 步；新/旧整数步数差为 42–149013 步，均为正。

作为描述性比较，q 的 T/(d h_d) 对解析系数 C_q 的全网格最大相对误差为 0.343458%，d≥128 为 0.022459%。该误差没有注册为独立预测。实际参数曲线与完整谱递推的最大差为 8.118506e−15。新控制只排除“反例必须使用不缩放的极快模态和随 d 消失的快权重”这一必要条件；第二谱矩与参数目标范数仍改变，不能独立归因慢模态质量，也未识别任何真实网络宽度边界。

方法与条件

实验实际优化参数 θ，逐步计算损失与梯度。谱公式只用于独立预算预测与核验，不用于生成训练曲线。使用 n=d 的满秩样本特征，以及 n=8192、前 d 个非零样本的零填充控制。两者均取 X[i,perm[i]]=√(nλᵢ)·sign[i]、yᵢ=√(nwᵢ)，其余元素为零；perm 与 sign 对应 π 与 sᵢ。同 d/seed 的两目标与新旧配对使用相同置换与符号。归一化谱、初始损失和参数目标保持一致，新增零模态没有目标能量。两目标的幂律系数、指数与 Rayleigh 反例在固定 n 条件下均保持。

旧两组没有删失（到运行上限仍未达阈值的情况）。每个 cell 到首次 L/L₀≤0.01 后再执行一步；旧两组上限为 5d，未达阈值原定保留删失。每组记账方案含 11 个维数×2 个目标=22 个条件，3 个坐标 seed=66 cell、33 个两目标配对。旧两组累计 132 cell，另有 66 个新旧预算配对。固定 n 的主判据为所有新旧预算差绝对值≤1 步；实际全部精确相等。原谱中间预算从 18 增至 18862 步，首尾从 35 增至 37724 步。

trace=1 对照也没有删失。它另含 22 个条件×3 个坐标 seed=66 个新 cell、33 个两目标配对与 66 个旧谱配对。有效累计训练为 198 cell，失效准备轮为 0 新训练/拟合。仅改谱整体尺度，目标权重、目标数组、置换与符号逐位沿用旧保存数组；上限改为 ceil(5 d h_d)，66/66 无删失。同 seed 报告配对范围。归一化同时改变初始梯度和参数目标范数，不能从该对照独立归因某个中介。

实验保存全损失曲线、输入合同、seed、检查点参数与源码 hash（文件内容摘要）。旧两组最多 19 个检查点，trace=1 组最多 23 个；最大参数检查点数组为 23×8192，不分配 d² 矩阵。运行环境是 CPU、NumPy float64（双精度浮点数）、单线程；θ₀=0，全批量 SGD η=0.5，无动量、无衰减。全部条件属于 development（已知条件上的开发验证），不是封存 OOD（未见新条件上的验证）。

失败与反例

单 Rayleigh 近似的反例全部保留。它在 33 个中间目标 cell 中精确命中预算，在全部 33 个首尾目标 cell 中低估 48.571429%–50.000000%。较大维数没有消除反例。联合维数实验的三个判据与固定 n 控制的两个判据均通过；这里的反例是注册预测得到支持，不是注册预测失败。没有删除或修订失败实验。

首尾目标的经验幂律不是每一区间的精确规律。d=8→16 的相邻指数为 1.040642，超过全网格拟合指数的注册上界 1.04。这不是全网格判据的失败。没有检验网格外维数，不把拟合误差当作外推保证。

trace=1 的候选对照在准备阶段失效。原因是临时解析脚本写入研究目录之外；未开展新训练或拟合。候选的两个误差判据均未评估。旧幂律、同 Rayleigh 预算反例和零填充对照保持原结果。

旧冻结 d 幂律不能在旧误差边界内描述有效 trace=1 的新预算。作为预先指定的描述性比较，它对中间/首尾新预算分别低估 63.027438%–89.515453% 与 62.619843%–89.475831%。新预算对 d 的拟合为 4.888044 d^1.177950 与 9.616830 d^1.180201，最大相对误差 15.540384%/16.570413%。这些数字超出旧条件的指数 [0.98,1.04] 和误差 6% 边界。有效 trace=1 对照的两个注册判据均通过；不追溯改判旧谱预测，也不把描述性比较登记为新注册失败。

ε=0.05 的评价没有产生新的训练或拟合失败。它只读复用 66 条旧曲线，不能支持连续阈值规律。

固定权重 q 的两项注册预测均得到支持，没有新增失败预测。单 Rayleigh 不充分的反例范围继续保留。旧 ε=0.05 研究目录缺少收尾核验回执；此次通过旧汇总最后提交与 74 个研究文件逐字匹配补充审计，如实保留缺口，不补造旧回执。一次写脚本的工具字符串错误在执行前阻止调用，未训练、未外写；修正后再冻结。

未决问题
