# D2 第二轮：没有标签噪声，泛化还会变差吗？

## 结论：多数例子经得起换一批新题，但不是全部

上一轮发现：即使训练标签全对，继续训练也可能让验证误差上升。但有一个疑点：我们用同一份验证集找最低点，又用它判断之后是否上升，可能把抽样波动当成规律。

这轮把模型和两个时间点全部锁住，只换一批新的验证输入。**51个可评价条件中，44个仍有明确回升，7个暂时判断不清。** 另外3个原本停在观察窗口末尾，不评价窗口外的变化。这里的条件是“样本数×已有种子×交互强度”，不是51种独立任务。

因此，在这批固定特征回归模型上，“泛化变差全是记住错误标签”解释不够：没有错误标签也能变差，而且多数例子不能仅归因于旧验证集选点。**具体为什么变差，仍未确定。** 当前结果也不适用于所有模型或所有任务。

## 我们到底在比较什么

把某个训练过程在两个时刻的模型存下来：旧验证集选出的时间t，以及继续训练到2t。让两个模型回答同一批新题，比较平均平方误差（MSE；越低越好）。

Δ = 新题上的MSE(2t) − 新题上的MSE(t)。Δ为正表示继续训练后变差。新题只用于评价，不重新选时间、不重新训练、不调整门槛。

| 保持不变 | 这轮唯一改变 |
|---|---|
| 训练输入、无噪声标签、特征、初始化、学习率和两个时间点 | 验证输入换成131,072个新高斯样本 |
| 32/64/128训练样本，3个已有主种子，6种交互强度 | 新样本分成32批，用批间波动估计误差条 |
| 目标 y=(x₀+αx₀x₁)/√(1+α²) | 没有加入新任务或新训练抽样 |

α=0是线性目标；α越大，x₀与x₁共同决定答案的部分越强。模型仍为128个固定ReLU特征加常数，只训练输出层。

## 结果有多可靠

我们提前规定：51个条件中至少41个的误差条下界超过旧初始MSE的百万分之一，才支持“至少八成能复现”。结果是44/51，达到门槛；这不等于证明所有条件都回升，也不表示回升都有实际应用意义。

| 结果 | 数量 | 怎么理解 |
|---|---:|---|
| 有明确回升，且超过预设极小门槛 | 44/51 | 换新验证输入后，回升仍能辨认 |
| 暂时判断不清 | 7/51 | 误差条跨过0，既不能确定回升，也不能确定没有回升 |
| 明确不回升 | 0/51 | 没有区间整体落在0及以下的条件 |
| 原窗口边界，不进入上述分母 | 3/54 | 不能评价原窗口之外 |

只看估计值，49个上升、2个下降；那2个都属于“判断不清”，不包装成明确反例。此前51/51的旧验证观察，现应改为44个得到明确新证据、7个待定。

| 交互强度α | 明确回升/可评价 | 暂时不清 | 边界 |
|---|---:|---:|---:|
| 0 | 6/6 | 0 | 3 |
| 0.125 | 9/9 | 0 | 0 |
| 0.25 | 8/9 | 1 | 0 |
| 0.5 | 7/9 | 2 | 0 |
| 1 | 7/9 | 2 | 0 |
| 2 | 7/9 | 2 | 0 |

一个明显例子：n=32、seed=6102、α=2，第773步到1546步。

| 指标 | 继续训练后的变化 |
|---|---:|
| 训练MSE | -0.00177，训练题做得更好 |
| 新验证MSE | 0.17441 → 0.18166，新题做得更差 |
| 新验证MSE增量 | +0.00725 |
| 增量的近似同时置信区间 | [0.00667, 0.00783] |

这里“无噪声”只说明答案没有人为加错，不说明有限训练样本已经充分代表总体，也不保证固定特征能表达目标。后两者是候选解释，本轮没有区分它们。

## 方法：先锁定，再评价

1. 校验上一轮62个保存产物和9份原始输入，冻结54条件；先排除3个窗口边界，再锁定51对模型权重。
2. 在锁定之后，按预注册随机数生成规则一次产生32×4096个新输入。所有模型共享这些题；同一条件的前后模型也共享题，因此比较的是配对差。
3. 每批算前后MSE和差值，以32个批均值的标准差除以√32作为标准误。用t分布、31自由度，并为51次比较作Bonferroni调整，临界值3.641。
4. 根据预注册的区间和门槛分类，保留全部结果；没有根据这次结果挑新的最低点。

这些区间近似控制整组比较的抽样误差，不是有限样本严格保证；它们只反映“这批固定模型遇到新输入”时的估计精度，不能当成32次独立训练或训练种子泛化证据。旧验证输入用了正负配对，新输入为独立同分布抽样：总体分布相同，抽样方差可以不同。

## 下一问：是目标表达不足，还是有限样本把学习方向带偏？

下一轮先建立这套高斯输入、固定ReLU特征的总体风险解析核对：用总体矩直接评价同一批冻结模型，检查7个待定条件，区分真实方向差异与剩余的验证抽样误差。这个步骤也为之后把目标换成“特征可以表达的目标”提供可核对的定义。

随后才考虑可表示目标的干预：若表达不足被去掉后仍会回升，就不能把表达不足当成必要原因。以上为候选下一问，尚未预注册或执行；不会为凑轮次重复已经明确的44个结果。新验证条件看过后也归入development。
