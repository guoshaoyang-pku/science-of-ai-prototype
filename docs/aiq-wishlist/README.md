# AIQ 许愿池页面初版

入口：`index.html`。这是仓库内的静态交互页面，无构建步骤、外部字体、第三方脚本或网络 API。

页面按“选方向 → 找灵感 → 写愿望”引导。默认仅展示当前步骤；证据与补充说明按需展开。每个 aspect 的“看看已有研究例子”按需展开 D1—D13：保留编号、一句问题、一句当前边界；点击后在阅读室打开对应 HTML 报告，可切换文献对照、单独打开或返回许愿池。13 个问题可跨 aspect 关联，归类为建议；评测与知识维度是横向关联，不表示已经验证解题收益。

八个 aspect 与候选愿望来自 `../AIQ_WISHLIST.md`，均保留“建议”标记。

视觉采用独立的研究手账风格：暖白纸张、钴蓝线稿、黄色便笺、左侧大标题与右侧方向目录。交互包含蓝色下划线、纸页转场、按压按钮和保存盖章反馈；装饰没有表示真实实验数据。页面不自动填入或提交愿望。

顶部可关闭动效，系统的减少动态效果设置优先。输入框仍使用原生文本编辑，支持中文输入法、选择和光标。草稿与已保存愿望沿用原存储键，视觉更新不迁移或清空记录。

## 使用

在仓库根目录启动本地静态服务：

```bash
python3 -m http.server 8767 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8767/docs/aiq-wishlist/`。页面 HTML、CSS、JavaScript 与 SVG 文件需保持同目录；完整说明链接依赖仓库目录结构。阅读室复用 `../模糊方向/` 中的报告、样式、图片和文献页，需一起保留；没有改写原研究报告。报告中的公式沿用原 MathJax 网络依赖。

愿望与未提交的新愿望草稿保存在当前浏览器的 localStorage，不是多人共享数据库。更换浏览器、端口或清除网站数据后，原记录可能不可见；会前可导出 Markdown 或复制文本。不会触发实验、solver 或发布流程。

## 文件

- `content.js`：八个方向的短解释、已有边界与建议示例。
- `directions.js`：13 个已有问题与边界，关联 `../模糊方向/` 下的图文报告和文献对照。
- `glyphs.js`：八个方向的本地静态 SVG 图标。
- `notebook.svg`：问号便笺插画。
- `index.html`：可访问的三步表单、证据折叠区与愿望列表。
- `style.css`：桌面和窄屏布局、键盘焦点及减少动态效果支持。
- `app.js`：步骤切换、草稿、保存、编辑、删除确认与导出。
- `preview.png`：首页浏览器预览截图。
- `examples-preview.png`：已有研究例子展开后的浏览器截图。
- `reader-preview.png`：许愿池内嵌研究报告的浏览器截图。
