| D2 | 风险何时回升，能否预测最低点？ | 最新 12/12 recipe 不支持扩域后只换系数的指数 1 律；train 无须先接近零 | 特征谱、目标能量与噪声响应的跨任务预测；train-only 未建立 |
| D3 | 容量与分辨率如何测量？ | 完整目标加权谱决定残余，少数标量不确定预算；空间分辨率未操作测量 | 复用轨迹检验 ε=.0001；学习特征边界未测 |
| D4 | 单 sigmoid 的参数和边界？ | 成败依赖谱比、慢损失占比和拟合协议；换协议不能消除全部失败 | 复用 α=.9 曲线检验最差误差下界 |
| D5 | LN 同宽度收益由什么中介？ | 收益测得，条件数/Rayleigh/均值耦合尚未解释；初始固定核 0/20 匹配训练 | 区分 weight decay、核漂移与其他非线性 |
| D6 | 早期核漂移能预测晚期吗？ | 原抽样上的关系不跨指定新抽样；输入/目标/归一化未独立归因 | 新方向性描述，在新 draw 上先注册预测 |
| D7 | train 受益而泛化受损的边界？ | 终点差距、噪声扩大差距和晚期回升是不同指标；依赖噪声实现 | 机制比例与 train-only 前瞻信号 |
| D8 | bias 和奇偶通路规律存活多远？ | 小尺度 a²/a⁶ 有受控证据；有限尺度有反例，性能收益未验证 | 新尺度 a=.0625；再测非对称、多层、CE |
| D9 | 小批量噪声怎样改变最低点？ | 条件矩消除轨迹平均误差；两条件 B8→B4→B2 最低点延后，不构成连续律 | 保持合同只改 B2→B1；保留逐位核验失败 |
| D10 | 深度中的动力学怎样传播？ | 最慢参数组高估；全核部分宽度族通过，时间不随深度单调 | 一个新学习率或深度的冻结预测 |
| D11 | width/n 标度与 lazy→rich 边界？ | 已测固定特征维数，不是真实 width；同 Rayleigh 仍有预算反例 | 同谱匹配前两矩新目标；真实 lazy/rich 未测 |
| D12 | sigmoid 失败后能否分解为级联？ | 无拟合双段候选只在部分离散条件通过；初始损失占比改变判定 | α=.9 曲线；三模态/merging/真跃迁未测 |
| D13 | Linear Flow World 相变时间与有效深度？ | 读出依赖显著，无 skip 深度单调标定失败；skip 组合律未测 | 三 seed 稳健性，或指定串联/并行/residual skip |
