# SAI 定义

2026-10-28。本文是 SAI（Science of AI）的当前定义全文，panel 第一、二节是它的压缩版。来源分三类，逐处标明：**用户原意**（用户在讨论中给出的定义、锚点和三轴手绘图）、**已有协议**（[第三轴协议](literature/nonapplicability_measure_protocol.md)等研究库文件）、**本文提出**（接手后为补全定义做的操作化与批判，可以推翻）。冻结论文 `main.pdf` 中的旧定义（以机器可读、程序裁决、预注册盲测作为层次准入）由本文取代，冻结稿本身不改。

## 0. 一句话

**核心想法**（用户原意，2026-10-29）：衡量科学家的直觉。等价算力（计算量）是目前唯一定量的判据；更多的研究对象是知识怎样产生、知识在什么范围内成立。

本文提出的对应：直觉指科学家（人或模型）不把实验跑完就判断结果的能力，是一种代价近 0 的答案规则（§1）。§2.6 的等价算力 ρ\* 衡量它值多少算力；§3 的三层说知识怎样产生、边界怎样知道；§2 的声明域与不适用测度 u 说知识在哪里成立。

SAI 研究 AI 系统（训练过程、模型、智能体）在给定条件下会怎样，目标是**以更小的误差、更低的代价、在更大的条件范围内预知结果**，并说明**为何如此、何时失效**。

压缩的直觉（用户原意）：用更少的信息或试探知道结果。它落在代价轴上，不以最小描述长度为中心。

## 1. 基本单位：主张

分类和计量的单位是一条**主张**，不是论文、作者或系统。一篇论文可以同时含方法、观察、经验关系和推导，它的主标签只是组织方式，也不代表价值高低。

一条主张写成四元组（本文提出）：

| 成分 | 含义 |
|---|---|
| 问题族 q | 对每个条件 ω 要预测什么，例如「两个训练配置谁的最终验证损失更低」 |
| 合同 (Ω, μ, ℓ, ε) | 条件空间、条件上的权重、损失和容忍度，见 §2 |
| 答案规则 M | 对每个 ω 给出答案或声明「不适用」，并写明版本 |
| 声明域 D_M ⊆ Ω | M 愿意作答的条件集合，以及给出这个集合的依据 |

方法类论文（如 GRPO）同样适用：方法本身不是主张，「在设定 S 下使用该方法会得到结果 R」才是主张。

## 2. 三轴：一条主张好在哪里

### 2.1 合同

先固定合同，再谈坐标（已有协议）：

- **Ω 条件空间**：任务 × 架构 × 超参 × 数据 × 预算的全部组合。一个元素是一次完整的训练或评测设定，不是一个数据样本。
- **μ**：Ω 上的概率权重，说明关心哪些设定、各占多少。它可以是实际部署分布，也可以是预先定义的研究设计；它不代表「整个世界」。
- **ℓ 与 ε**：损失与容忍度，以及随机结果按期望、分位数还是失败概率判定。
- **真值**：把该设定实际跑完得到的结果。

### 2.2 三个坐标

三个坐标都在 0 到 1 之间，都越小越好（用户原意：误差、代价、反向的普适性）。下面的具体定义由本文提出：

- **误差 e**：在声明域 D_M 内，答案超出 ε 的条件所占的 μ 比例。
- **代价 c**：得到答案所花的计算、试探和信息，以「直接把这次训练跑完」为 1，在 D_M 上按 μ 取平均。c 超过 1 的方法被直接训练支配，所以截断在 1。
- **不适用测度 u**：M 不作答的条件的 μ 测度，u = μ(Ω \ D_M)。

声明域内出错计入 e，声明不作答计入 u。因此**越界声明（overclaim）表现为 e 升高，诚实划界表现为 u 升高**。已有协议中的理想量 u\*(ε) = μ(Ω \ D\*_M(ε)) 是边界被完美知道、且 e = 0 时 u 能达到的下限。

### 2.3 两个参照点

- **直接训练**位于 (e ≈ 种子噪声, c = 1, u = 0)：精确、处处可用、最贵。它的误差不是严格的 0。若问题是期望结果，单次运行带种子方差，这是真值本身的噪声底。
- **原点** (0, 0, 0)：零误差、零代价、处处适用。用户把它比作「万物理论」，这是理想方向，**不是已证的数学等价**。

用户手绘图中标 "Science" 的箭头从直接训练指向原点：科学的方向是用越来越少的试探得到同样的答案。图中的 U 点代价接近 0、误差大于 0，是便宜但不精确的候选规律（本文读作研究线中的有效时间 U，可由用户更正）。

### 2.4 边界已知的价值

本文提出：若主张知道自己在哪里不适用，那部分可以回退到直接训练。组合方法的坐标为

```
e' = (1 − u)·e,   c' = (1 − u)·c + u,   u' = 0
```

也就是说，u 可以按单价 1 换成代价。不知道边界的主张做不到这一点：它在未知位置出错，使用者无法挑出该回退的条件。例如，两个方法都在 30% 的条件上失败：一个照常作答，坐标是 (0.3, c, 0)；另一个知道失败在哪并拒答，坐标是 (0, c, 0.3)，回退后变成 (0, 0.7c + 0.3, 0)。这是 §3 把「怎样知道边界」作为层次判据的理由。

### 2.5 估计与限制

已有协议的结论，必须随坐标一起报告：

- 三个坐标都相对于合同。换 μ，u 会变；比较两条主张必须使用同一份合同，否则坐标不可比。
- 有限实验只给估计和上界。n 个独立条件全部成功时，单侧 1−δ 上限为 1 − δ^(1/n)：n = 100 时 95% 上限约 2.95%。未测的条件记为未知，不算成立。报告 u 时，把「已证不适用」与「未测」分开列出，坐标取保守值（两者都计入 u）。
- u = 0 表示在 μ 下几乎处处适用，不等于逐点无例外。
- 相关样本（同数据的重复 seed、重复 prompt）不是独立条件；用测试结果反复挑模型或阈值后，简单的区间解释不再成立。

### 2.6 与等价算力的关系

panel 的等价算力 ρ\* 是这套坐标的一个切片：对一个知识来源，先测它在 ArchitectureIQ 合同下的误差，再问基线试探策略要花多少代价 c 才能达到同样误差，这个 c 就是 ρ\*。它把误差折算成代价。

## 3. 三层：边界是怎么知道的

用户给出了三层的内容；本文提出用「声明域 D_M 的依据」统一操作化。三层的区别不在范围大小，而在**边界是观察到的、系统扩展测到的，还是从原理推出的**。

### Knowledge（知识）

> 用户原意：一个或少数具体设定下观察到的现象，外延尚未充分展开。

- 依据：在具体测过的条件上观察到结果。
- 声明域：诚实的知识主张只声明测过的设定及其近邻，所以 u 通常接近 1；没有声明域的知识主张等于默认处处适用，此时 e 在大部分 Ω 上未知。
- 对新条件：不作预言。
- 锚点（用户指定）：GRPO、GSPO。

### Law（定律）

> 用户原意：系统扩展外延、尽量解除约束后保留下来的稳定关系。

- 依据：沿声明的条件轴系统地改变条件，逐轴记录「已测且支持、已测且失败、测量不足、未测」。
- 边界：由观测到的失败定位。**预算用完不等于到头**；发现必要的限制，就把它写进定律，这不算研究失败。
- 声明域：以已测外延为界。越界外推（例如更大规模）是一条新的、证据更弱的待检主张。
- 形式：通常是用少量参数概括一族结果的关系，所以在 D_M 内 c 很低。拟合的生产代价另记（§5）。
- 锚点（用户指定）：scaling law。

### Science（科学）

> 用户原意：从第一性原理知道关系为何成立，以及边界在哪里。

- 依据：从前提演绎出关系。本文提出，「第一性原理」的可操作含义是前提满足三条：(a) 显式写出；(b) 可以独立于所预测的关系去检验，不能把拟合出的关系换个说法当作前提；(c) 结论由前提推出，边界就是前提失效的地方。
- 单条明确的条件推导即可，不要求推出多条定律、引入新坐标或通过盲测。
- 必须分开两问：**推导在假设内是否正确**（数学问题），以及**前提在真实系统中是否成立**（映射问题，要像定律一样用实验检验）。
- 推导只给出充分条件时，推出的边界是内界：界外是未知，不是已证失效。
- 对新条件：在前提已核验的条件上可以作答，即使结果本身没测过。这是科学在三轴上相对定律的实际优势：检验前提通常比跑出结果便宜，而且回退的位置是已知的。
- 锚点（用户指定）：Hyperball 按主贡献是科学。它的尺度不变性代数在假设内成立；真实网络只近似满足这些假设，批评文给出竞争解释。

### 晋升与降级

- 知识 → 定律：沿条件轴扩展外延，记录支持、失败和未测。
- 定律 → 科学：找到可独立检验的前提，推出关系与边界。
- 降级：声明域内出现反例时，先收窄 D_M，降低 e；收窄后不再满足本层依据时，降一层。证伪记录保留。

### 不构成层次依据的东西

以下都不自动构成科学，也不自动升层：形式定义、程序可执行、一次验证、高分、预注册、盲测、机器可读。它们属于 §4 的证据协议。

## 4. 分开记录的四件事

| 维度 | 回答的问题 | 例子 |
|---|---|---|
| 层次 | 边界是怎么知道的 | 知识 / 定律 / 科学 |
| Scope | 适用范围多大 | 合同 (Ω, μ, ε) 下的 u 及其上界 |
| 证据协议 | 坐标有多可信 | 预注册、盲测、新鲜题、程序裁决、独立复现、证明核查 |
| 阅读层级 | 我们读到了多深 | 研究库的 `review_level`：元数据、摘要、指定章节、全文 |

窄域推导可以是科学，广域经验关系仍是定律。一条预注册过的观察仍是知识，一条未经实验检验的推导仍是科学（只是映射问题悬而未决）。

## 5. SAI 作为系统

旧稿把 SAI 定义为「对象 + 系统」两义。本文保留第二义，但把它降为派生概念：**SAI 系统是自动产出 §1 主张的系统**。评价它看三件事：

- **前沿推进**：在一份固定合同下，它产出的主张把 (e, c, u) 前沿向原点推了多少。
- **生产代价**：产出这些主张花的计算，与使用代价 c 分开记。一条拟合花了 10⁶ GPU 小时的定律，使用起来可以很便宜。
- **划界诚实度**：它声明的 D_M 里实际出错的比例，即 overclaim 率。

里程碑梯子 M0–M6 是对系统的另一种评分，不是主张的层次。

## 6. 批判与未决

1. **Ω 和 μ 没有天然的选择。** 不存在「所有 AI 系统」上的典范测度，所以 u 只在共同合同下可比。跨主张比较需要一份公开的条件基准（一组 Ω、μ、ε）。目前只有 ArchitectureIQ 接近这一角色，它的 Ω 很窄。
2. **真值有噪声底。** 直接训练的 e 不为 0，期望型问题需要重复种子。种子方差小于某个阈值的问题才适合判对错。
3. **代价的口径要统一。** c 应同时计算力和信息（试探次数、需要看的训练前缀）。不同硬件、不同实现会改变绝对数，所以统一用相对直接训练的比例。
4. **「第一性原理」是相对的。** §3 的 (b) 条是最低防线：前提必须能脱离结论单独检验。它挡不住所有循环论证，判定仍要逐条审。
5. **三轴不决定层次。** 同一坐标的两条主张可以有不同依据；坐标是相对合同的，层次是依据的类型。二者都记，不互相推出。
6. **层次不是价值排名。** 一条覆盖面广、便宜、准确的定律，可能比一条窄域科学更有用。
7. **与冻结稿的差异。** 冻结稿把机器可读、程序裁决、预注册盲测写进层次准入；本文把它们移到证据协议。冻结稿的「RL 51 篇：43 / 3 / 5」统计按旧门槛得出，只作历史口径。

## 7. 记录模板

每条主张至少记录：

- 主张原文与来源版本（论文、页码、版本日期）
- 问题族 q 与答案规则 M（含版本）
- 合同：Ω 的轴与取值范围、μ、ℓ、ε、随机性判定方式
- 声明域 D_M 及依据类型（观察 / 系统扩展 / 推导）
- 坐标：e、c、u 的点估计与上界；u 拆为已证不适用与未测两部分
- 逐轴记录：已测支持、已测失败、测量不足、未测
- 科学类另记：前提清单、每条前提的独立检验状态、推导核查状态、充分或必要
- 证据协议与阅读层级
- 已知反例与证伪记录

研究库 JSON 现有的 claim、scope、evidence、review_level 字段对应其中一部分；e、c、u 和合同字段尚未进入 JSON，补字段需另行讨论，不在本次改动内。
