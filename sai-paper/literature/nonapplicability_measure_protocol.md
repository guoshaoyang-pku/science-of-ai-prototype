# 第三轴如何测量：不适用范围、采样与不确定性

用户图中的第三轴不是“普适性得分越大越好”，而是一个反向量：在多大范围上，该预测方法不适用。这个量必须先说明测度，才能计算或比较。它可以用于研究 Knowledge、Law 或 Science 各自的 scope；三轴坐标本身不能自动判断一项研究属于哪个层次。

## 1. 先把“适用”写成合同

固定：

- **目标条件空间** \(\Omega\)：例如模型架构、数据分布、训练预算、优化器、随机种子及评价任务的集合；这里的元素是一个完整条件，不一定是单一数据样本。
- **方法 \(M\) 和评价对象**：待预测的量、预测时可用的信息以及模型版本；如果先用某个数据集选择方法，再用同一数据集评估，需要将这一选择过程纳入评价设计。
- **损失与容忍度**：规定 \(\ell\) 和 \(\varepsilon\)，以及面对随机结果时是看期望损失、分位数、失败概率还是别的性质。
- **条件测度 \(\mu\)**：一套对 \(\Omega\) 中条件加权的概率规则。它可以是某个实际部署分布，也可以是预先定义的研究设计；不是所有测度都代表“整个世界”。

令 \(D^*_M(\varepsilon)\subseteq\Omega\) 表示在上述合同下方法实际达标的条件集合。理想的第三轴是

\[
u^*(M;\Omega,\mu,\varepsilon)
=\mu(\Omega\setminus D^*_M(\varepsilon)).
\]

它是**未知目标量**，不是有限实验自动得到的真值。不可测集合、未定义的损失或未指定的随机性规则都会使这一写法无法直接使用；这里只讨论相关集合可测、\(\mu\) 为概率测度的情况。

## 2. 用抽样估计：零失败不等于零不适用

假设方法与评价合同在测试前已固定，测试条件 \(\omega_1,\ldots,\omega_n\) 独立同分布于 \(\mu\)，且每个条件是否不达标都能无误判定。记失败数

\[
K=\sum_{i=1}^n
\mathbf 1\{\omega_i\notin D^*_M(\varepsilon)\},
\qquad K\sim\operatorname{Binomial}(n,u^*).
\]

点估计 \(K/n\) 应与不确定性一起报告。若 \(K=0\)，在上述假设下，单侧 \(1-\delta\) 精确上置信限为

\[
u_{\rm upper}=1-\delta^{1/n}.
\]

这是基于 \(P(K=0\mid u)=(1-u)^n\) 反演得到的：测试 100 个独立条件且均成功时，95% 单侧上限约 2.95%；测试 1000 个独立条件且均成功时约 0.299%。若要以这种零失败设计将上限压到 0.1% 以下，至少需 2995 个独立条件。它是频率意义的置信限，**不是**“第三轴真值以 95% 概率在此以下”。

若观察到 \(0<K<n\)，可用单侧精确二项分布上限，求解

\[
\sum_{j=0}^{K}{n\choose j}
u_{\rm upper}^{j}(1-u_{\rm upper})^{n-j}=\delta.
\]

\(K=n\) 时上限取 1。保留失败个例和未测试条件比仅给一个汇总数字更能帮助寻找边界。

### 上式什么时候不能直接用？

- 从同一个数据集产生大量相关样本，不能把它们当作独立条件；重复 seed、重复 prompt 与跨架构／跨任务抽样具有不同的统计单位。
- 通过同一批测试结果反复选择模型或阈值后，再按固定模型计算上述区间，会破坏简单的覆盖解释。应保留独立评估集，或对选择过程作相应校正。
- 若“适用”定义为给定条件下的**期望损失**不超过阈值，单次随机输出通常不能确定该条件是否适用。需要对条件内随机性充分重复、设计误判控制，并将剩余不确定性单独报告。
- 抽样分布 \(\mu\) 与声称的目标分布不一致时，区间描述的是抽样合同下的失败测度，不自动覆盖另一分布；未抽样的条件也不是已证明成功。

## 3. 改变测度，结论会怎样？

设两个可测概率分布 \(\mu,\nu\) 的失败集合相同，若 \(\nu\) 对 \(\mu\) 绝对连续，且密度比满足

\[
\frac{d\nu}{d\mu}\le B\quad \mu\text{-几乎处处},
\]

那么

\[
u^*(M;\nu,\varepsilon)\le B\,u^*(M;\mu,\varepsilon).
\]

推导直接来自对失败集合积分。若密度比有界性不成立，或 \(\nu\) 把质量放在 \(\mu\) 从不抽到的区域，即使在 \(\mu\) 下估计的失败率很低，也不能从该结论直接推出在 \(\nu\) 下仍低。\(B\) 较大时，这个上界可能非常宽，应按最多 1 截断。

这与用户所说的“普适性”直接相关：同一个方法的失效集合不变，**改变关注哪些条件及它们的权重**，第三轴数值也会改变。声明“在多大测度上不适用”时，必须一起声明所用测度。

## 4. 零测度与真正无例外

设 \(\Omega=[0,1]\)、\(\mu\) 为均匀分布，一个方法除 \(x=0\) 之外全部正确。对 \(\mu\)，失效集合 \(\{0\}\) 的测度是 0；然而在把全部质量放在 \(x=0\) 的测度下，不适用测度是 1。

所以，**第三轴为 0 表示在指定测度下几乎处处适用，并不意味着逐点无例外**。将三轴原点视作“万物理论”的理想图景，还必须定义目标空间、测度、预测误差与信息成本，并论证这种论断为何覆盖我们关心的所有系统。有限次未见失败或单一分布下的零测度均不足以单独确立它。

## 5. 与论文层次如何衔接

- **Knowledge**：固定一个或少数设置，记录现象、方法及失败；这些测试点给出局部证据。
- **Law**：针对明确的目标族，系统改变条件并记录关系的支持、反例与未知；第三轴刻画某个测度下已定义规则的覆盖，不自动证明边界已经穷尽。
- **Science**：在明确数学模型里推导边界或不可能性。若证明完整边界，还要核查数学模型映射到现实条件的范围；条件化定理不能仅凭名称占据真实系统的零不适用原点。

报告格式建议为：**方法和版本；目标集合及测度；成功判据；测试如何抽样；条件内重复及误判处理；失败数与区间；已知失败／未测轴；模型选择是否使用测试数据**。数学公式是本记录在写明假设下的推导，不是对当前文献库全部论文已完成此种评测的宣称。
