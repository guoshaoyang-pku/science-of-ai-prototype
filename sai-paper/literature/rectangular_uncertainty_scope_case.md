# 一个 Bellman 计算为什么会算错：不确定条件能否独立拼接

本例由本资料库构造，不是原论文的例题或实验，不增加论文、概念计数。它给出一个可以精确推导边界的 Scope 案例：即使每个局部最坏情形都合法，把它们拼在一起也可能违反系统的联合约束。

## 1. 模型、目标与对手的时序

系统只有两步转移。初始状态 s 以各 1/2 的概率进入 x 或 y；从 x 以概率 p 成功，从 y 以概率 q 成功，否则失败。成功、失败都是终止状态，终端奖励分别为 1、0。没有控制动作，等价于只评估一个固定策略。这里不使用无限时域或折扣回报。

对手在初始随机转移之前选择完整的一对 (p,q)，随后固定使用该模型。可选集合为

\[
\mathcal P_\delta=\{(p,q)\in[0,1]^2:|p+q-1|\leq\delta\},\qquad 0\leq\delta\leq1.
\]

我们要求的是在这一**联合约束**下的最坏期望成功率。对手不能观察到实际进入 x 还是 y 后，重新挑选另一对参数。两行转移是否能独立拼接，是比较合同的一部分。

## 2. 正确值与逐行计算值

对任意固定 (p,q)，期望回报是 (p+q)/2。联合约束给出 p+q≥1−δ，而 (0,1−δ) 在集合中，故最小值可达：

\[
V_{\rm joint}(s)=\min_{(p,q)\in\mathcal P_\delta}\frac{p+q}{2}=\frac{1-\delta}{2}.
\]

现在考虑一个忽略联合约束的计算规则：在 x 处分别找最小 p，在 y 处分别找最小 q，再把两个局部值带回初始状态。

每一行单独看都有整个 [0,1] 的可选范围：任给 p，取 q=1−p 即可满足约束，反之亦然。因此这条规则得到

\[
\widehat V(x)=0,\quad\widehat V(y)=0,\quad\widehat V(s)=0.
\]

x 的局部最坏值可由 (0,1) 实现，y 的局部最坏值可由 (1,0) 实现。但是，它们拼成的 (0,0) 只有在 δ=1 时才属于原集合。逐行规则实际上把 \(\mathcal P_\delta\) 扩张成了 \([0,1]\times[0,1]\)，也就是允许各行独立选择的矩形包。

| δ | 原联合模型的最坏值 | 逐行规则的值 | 绝对误差 |
|---:|---:|---:|---:|
| 0 | 1/2 | 0 | 1/2 |
| 1/4 | 3/8 | 0 | 3/8 |
| 1/2 | 1/4 | 0 | 1/4 |
| 3/4 | 1/8 | 0 | 1/8 |
| 1 | 0 | 0 | 0 |

这不是浮点误差，也不说明 Bellman 方法普遍无效。错误发生在用独立的逐行最小值替代一个有耦合约束的联合最小值。本例中“静态”与“动态”对手的差异源于这种耦合；不能由此声称所有静态不确定模型都不适用动态规划。保留联合约束的全局优化可直接求得正确值。

## 3. 第三轴：可以推导的不适用测度

固定上述系统族、初始分布、终端奖励和逐行计算规则。把条件空间设为 \(\Omega=[0,1]\)，条件坐标为 δ，测度 μ 设为均匀分布。设允许绝对误差为 ε≥0，把误差严格大于 ε 定义为不适用。

因为误差恰为 (1−δ)/2，故

\[
F_\varepsilon=\{\delta\in[0,1]:(1-\delta)/2>\varepsilon\},\qquad
\mu(F_\varepsilon)=\max(0,1-2\varepsilon).
\]

ε=0 时，规则只在 δ=1 精确，不适用测度为 1。ε=1/4 时为 1/2。ε≥1/2 时为 0，但此时零不适用测度来自较宽的容错要求，不表示规则已经精确或获得普适理论。

这里的 μ 只作用于已声明的单参数模型族。若把全部概率质量放在 δ=1，测度也会变成 0；若改变初始分布或目标，公式需要重推。它不估计现实 RL 问题中“有多少”满足矩形性。

## 4. Knowledge、Law、Science 的不同证据

- **Knowledge**：在某个 δ 上发现局部计算与真实值不一致，报告该系统及观测误差。
- **Law 的证据任务**：在声明的条件族中系统改变耦合程度、初始分布、奖励和时域，检验一个经验关系并报告失败与未知条件。只扫几个 δ 不足以证明外延已穷尽。
- **Science**：从联合约束推出正确值、逐行规则的误差、精确成立条件 δ=1，以及给定 Ω、μ、ε 下的不适用测度。以上是模型内的条件性结论；现实不确定性是否符合这个集合，需要另外的辨识证据。

因此，Science 层次可以由“知道方法为什么会失败、边界在哪里”体现；它不要求该方法在所有条件下成功。判定单位是具体主张，不能把“使用 Bellman 方程”本身当作 Science 标签。
