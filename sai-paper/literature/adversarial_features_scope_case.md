# 对抗特征：从单范式有用性到跨范式有用性

这是一组具体主张的比较，不是对所有对抗样本或所有自监督学习方法的结论。两篇论文都已收录在 `interp.json`；以下核对的是所列章节和表格，并未独立运行训练或攻击。

## 研究问题和条件

|  | Ilyas 等，2019 | Li 等，2023 |
|---|---|---|
| 原文 | [Adversarial Examples Are Not Bugs, They Are Features](https://arxiv.org/abs/1905.02175)，v4 PDF §2–3 | [Adversarial Examples Are Not Real Features](https://arxiv.org/abs/2310.18936)，v4 PDF §2–4 |
| 主要问题 | 有些对标准分类有用的信息能否被允许的对抗扰动破坏？ | 从特定监督模型构造的特征数据，在不同学习范式中是否仍然有用或鲁棒？ |
| 有用性 | 二分类中，给定分布 D，特征 f 满足 E[y f(x)] ≥ ρ > 0。 | 给定数据处理 g 和学习范式 T，训练编码器并以线性探针的分类表现衡量；再比较指定范式集上的最差表现或相对表现。 |
| 关键条件 | 特征、数据分布、标签与扰动集合 Δ；相关性和扰动后的最坏相关性是不同对象。 | 特定监督模型产生的数据、CIFAR-10 / Tiny-ImageNet、MIM、对比学习、扩散和监督训练、指定探针与测试。 |
| 可以支持的结论 | 在原文的形式定义及实验设置下，一些有用信号对指定扰动不鲁棒；构造的数据可支持标准分类。 | 文中所测非鲁棒数据在监督训练和所测自监督范式下表现不同；所测鲁棒数据也不保证所得模型在所选攻击下鲁棒。 |

**这两种“有用”并非同一个谓词。** 一种是单个特征在指定分布上与标签相关；另一种还涉及数据构造、训练算法、表示、探针、对照基准以及跨范式最小值。因此，单范式相关性不能直接推出跨范式探针表现；后者较差也不自动否定前者的相关性。2023 年论文提出的“真正有用”是其特定操作性定义，不能直接当作与任务无关的真理标准。2019 年论文第 2 页脚注 1 也明确指出，其发现并不排除其他对抗脆弱性机制。

按本项目口径，两篇论文的这些实验观察属于 **Knowledge**；跨范式测量框架是拓展 scope 的尝试。要将更广的经验关系提升为 Law，仍需预先界定范式、数据构造与扰动等目标范围，开展跨条件的独立检验并记录失效情况。形式定义本身不是证明现实中唯一机制的 Science。

## 表 1 的可复算疑点

2023 年论文 §2.2 式 (11)、(13) 将跨范式相对有用性定义为各范式相对有用性的最小值；Table 1 的表注也称该列为四个范式的最差相对有用性。下面以 v4 PDF 第 6 页表格中**显示的四个数**直接计算：

| 数据与特征 | 表中四项最小值 | 表中汇总列 | 对照 |
|---|---:|---:|---|
| CIFAR-10 robust | 0.791 | 0.791 | 一致 |
| CIFAR-10 non-robust | 0.307 | 0.307 | 一致 |
| Tiny-ImageNet robust | 0.691 | 0.672 | 不一致 |
| Tiny-ImageNet non-robust | 0.074 | 0.134 | 不一致 |

两处差异大于显示精度所能解释的普通四舍五入误差。这里仅报告表内公式与显示数值的不一致：尚未核对作者代码、原始日志或其他版本，不能判断是单元格抄写、汇总计算、展示版本或其他原因，也不能据此断言整项研究结论无效。正文引用该表时，应避免把两处汇总数字当成已核实的精确结果。

另一个待核问题：v4 PDF §2.2 式 (8) 对扰动写的是正确分类指示函数的内部 `max`，而周围文字称其衡量对抗扰动下的鲁棒性；如果按通常最坏情况准确率的字面含义，内部方向需要核实。此处只记录公式与文字的潜在不一致，不推断作者实际攻击实现，不能把它当作实验代码错误的证据。
