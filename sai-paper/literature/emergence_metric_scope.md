# 能力涌现：模型变化与评价指标怎样区分？

[Wei 等《Emergent Abilities of Large Language Models》](https://arxiv.org/abs/2206.07682) §2–4 汇集了特定模型、任务和提示下，较小规模模型表现接近基线而较大模型表现提高的观察。[Schaeffer 等《Are Emergent Abilities of Large Language Models a Mirage?》](https://arxiv.org/abs/2304.15004) §2–5 对部分案例提出另一种解释：同一批输出经不同指标和采样精度测量，曲线可能有不同形状。后者的数学例子使用 token 正确性独立等假设，作者也明确独立性不符合真实生成的全部情况；其实验不证明所有可能的能力跃迁都是测量假象。

下文在原文所讨论问题上写出一个小型可计算例子；数学结果属于该例子的合同，不代表已复现论文的训练或评测。

## 1. 同一输出，两个评价量

假设某任务的输出与目标都恰有 \(m\) 个对齐 token。令每个位置正确的概率相同为 \(p\)，且本节进一步**假设各位置正确事件独立**。比较：

- **逐 token 平均正确率**：固定位置对齐后，\(A_{\rm token}=p\)。
- **完全匹配准确率**：只有所有 \(m\) 个位置均正确才记成功，\(A_{\rm exact}=p^m\)。

逐 token 平均正确率与本文的固定长度 Hamming 指标相对应；它不必等于允许插入、删除的 token edit distance。\(p^m\) 来自独立性和各位置成功概率相同，不能直接套用到有相关错误或不同长度的真实生成。

取 \(m=100\)：

| 每个位置正确概率 \(p\) | 平均 token 正确率 | 全序列完全正确率 \(p^{100}\) |
|---:|---:|---:|
| 0.90 | 0.90 | 约 0.000027 |
| 0.95 | 0.95 | 约 0.0059 |
| 0.98 | 0.98 | 约 0.133 |
| 0.99 | 0.99 | 约 0.366 |

两列来自**同一假定的输出分布**，并未换模型。逐位置正确率逐渐增加时，全序列成功率可在狭窄的 \(p\) 区间内快速变化。对于每个固定有限 \(m\)，\(p^m\) 仍是连续函数；“很陡”不等于证明真实系统发生不连续相变。

更一般地，若把“任务成功”阈值定为 \(q\in(0,1)\)，则该玩具模型达到阈值当且仅当

\[
p\ge q^{1/m}.
\]

达到 10% 与 90% 完全匹配率所需的 \(p\) 相差
\(0.9^{1/m}-0.1^{1/m}\)，当 \(m\) 很大时约为
\(\log(9)/m\)。这说明**阈值与序列长度共同决定表观跃迁的位置和宽度**，前提是该概率模型成立。

## 2. 单 token 平均准确率不能唯一确定完全匹配率

只知道每个 token 的边际正确率都是 \(p\)，不足以确定全序列正确率。例如 \(m=10,p=0.9\)：

- 若各位置正确事件独立，完全匹配概率为 \(0.9^{10}\approx0.349\)。
- 若所有位置共享一个 Bernoulli\((0.9)\) 结果，十个位置要么全对、要么全错，完全匹配概率为 \(0.9\)。

两个系统的每个位置边际正确率相同，结果却不同。逐位置平均正确率的期望仍为 \(p\)，因为期望可逐项相加；这个结论不需要位置独立。真实自回归生成中还应区分**无条件位置边际准确率**与**在此前 token 全正确条件下的下一 token 概率**：后者的乘积由概率链式法则给出，并不要求无条件独立。

## 3. 有限测试也会让非零成功率看起来是零

假设每道题的完全匹配成功事件相互独立，且成功概率都是 \(q\)。测试 \(n\) 题一次都没有成功的概率为

\[
P(K=0)=(1-q)^n.
\]

在上面的独立 token 模型里，若 \(m=100,p=0.95\)，则 \(q\approx0.00592\)。测试 100 题时，即使真实成功率非零，观察到零成功的概率仍约 55.2%；测试 1000 题时约为 0.26%。这是条件化抽样计算；题目之间相关、难度差异、重复采样或模型选择使用测试集时，不能直接使用上述简单二项模型。

因此，“较小模型没有观察到成功”应与测试题数、抽样方式及不确定区间一起报告；它不自动等于真实成功率严格为 0。

## 4. 放进 Knowledge–Law–Science

| 具体主张 | 分类 | 合同与限制 |
|---|---|---|
| 某组模型在某任务和计分指标下出现曲线突升 | Knowledge | 模型、任务、提示、采样、分数和数据量 |
| 在给定任务族与指标下，规模与得分的关系跨条件重复成立 | Law 或 Law 候选 | 需扫描规模、提示、长度、指标和留出任务；未知区域不等于已失败或已适用 |
| 固定长度且独立同分布正确事件下，完全匹配概率为 \(p^m\) | Science | 显式概率模型、固定 \(m\) 与独立性；不证明所有真实语言模型遵循此模型 |
| 更换指标或增加测试数据后，某些论文案例的表观突变减弱 | Knowledge | 作者实际测试的模型、任务、指标与统计协议 |

一个指标是否适合，也取决于任务：对必须逐位正确的答案，完全匹配可以是合理目标；它不能因此自动解释产生该得分曲线的内部机制。单次输出的计分函数即使是阶跃函数，其对有随机性的总体分布取期望后也可能平滑；反过来，平滑指标也不能保证模型机制本身没有真实跃迁。要区分这些解释，应保留原始输出，在同一测试集上比较指标，并在留出的模型尺度、任务和样本上检验预测。
