# 同一问题上，Knowledge、Law 与 Science 如何区分

这份比较说明分类单位是**具体主张**，不是论文标题。下文使用已收录的一手文献与已核对的指定位置；评价是本图谱的分类判断，不是对论文价值的排序。它不代表已逐行审查所有证明或独立复现实验。

## 一、从表格 Q-learning 的收敛到深度 Q 网络

**Science，部分理论边界。** [Watkins 与 Dayan 的 Q-learning](https://link.springer.com/article/10.1007/BF00992698) 对离散表格动作价值给出几乎必然收敛定理。已核对其原文 §2：在作者的折扣、有限状态／动作及有界奖励条件下，所有状态动作对被反复访问，且对应步长满足适当的可和性条件，结论是估计趋于最优动作价值。这里是关于明确随机更新系统的充分条件，不等于证明这些条件全部必要，更不等于任何神经网络 Q 学习都收敛。证明尚未逐行审计。

**Knowledge，具体方法与实验。** [Playing Atari with Deep Reinforcement Learning](https://arxiv.org/abs/1312.5602) 用卷积网络从画面估计动作价值，结合经验回放，并在作者的七个 Atari 游戏设置中评估；方法定位见原文 §4 和 Algorithm 1。它为高维输入上的可行性和表现提供条件化证据。这里用函数逼近代替表格，并不自动继承上述表格定理。2013 年七游戏结果也不能与 [2015 年的 49 游戏实验](https://www.nature.com/articles/nature14236)混成同一个实验。

**什么会构成 Law？** 例如明确一族 MDP、网络、数据采集、回放与学习率设置，规定收敛／失稳的观测标准，系统扫描这些轴并检验留出条件，才能提出并检验关于深度 Q 学习稳定区间的经验关系。现有两项结果本身不构成这样的完整扫描；即便有了，它也必须按所检验的条件报告，不能宣称所有 MDP 上有效。

## 二、规模规律：经验关系与可解理论模型

**Law，经验关系。** [Kaplan 等](https://arxiv.org/abs/2001.08361)在特定 Transformer、语料、训练和计算口径下拟合测试损失与参数、数据及算力之间的规模关系（§1.2、§3、§6）。这些不同拟合各自有条件，不能将它们视为所有因素同时任意变化时的一个无条件公式。[Chinchilla](https://arxiv.org/abs/2203.15556) 在另一组训练计算分配设置中研究最优参数量和 token 数；其结论是指定训练计算口径下的经验估计，不直接决定包含推理和部署成本的总成本最优。

**Science，条件化的理论解释。** [A Solvable Model of Neural Scaling Laws](https://arxiv.org/abs/2210.16859) 在潜变量、随机特征和线性回归等理想化假设下分析损失缩放（§3.1–3.2、§4.1）。它可以研究这些假设内的产生机制及部分边界；现实 Transformer 是否满足相应条件、该机制解释了多大比例的现实规律，仍是需要额外验证的问题。作者的模型并非对所有规模规律的完整现实证明。

比较重点不是给 Science 论文一个更高分数：经验规律的有效预测范围，和理论模型证明了哪些条件，是两份不同的证据合同。理论能够重新产生某种幂律，并不能单凭这一点证明它是现实系统中唯一的机制。

## 三、显著图：反例能推动范围修订，但不自动建立普适规律

[Adebayo 等](https://arxiv.org/abs/1810.03292)设计模型参数与训练数据随机化检查，发现一些所测显著图方法对这些变化不敏感；其论证同时包括指定线性和单层卷积模型的分析。对于具体模型、方法和测试，其实验结论可记为 **Knowledge**（§2–4），理论分析须单独按实际假设判断。

[Yona 与 Greenfeld](https://arxiv.org/abs/2110.14297)重新分析了测试中的任务混杂，并在自定义任务中观察不同结果（§1–4）。这给出需要认真考虑的边界与竞争解释，但不能据此推断所有显著图都可信，也不能把后一篇简单当作对前一篇所有结果的普遍推翻。

如果要把这个方向推进到 **Law**，需事先定义方法、模型、数据任务、随机化方式、解释用途和评价指标；选择能够区分输入结构与模型依赖性的对照，报告结果在哪些组合中成立、改变或未知。两篇的分歧提示了应扫描的条件轴，并不单凭分歧本身确定规律。

## 四、将比较落到索引时的规则

1. 记录论文主标签时，标明它对应的方法、经验现象或定理；对重要的其他主张建立独立记录。
2. 对 Law 区分“论文提出并检验了跨条件关系”和“目标空间边界已经充分描绘”。前者不自动证明后者。
3. 对 Science 写出具体假设和结论，区分充分条件、必要条件与完整边界；现实映射另列证据。
4. 保存反例、竞争解释与未知条件。小范围中的成功或失败都不能自动外推到未测条件。
