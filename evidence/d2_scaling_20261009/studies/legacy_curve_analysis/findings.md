# D2 曲线与机制图像复核

仅重分析 r003 的 60 条保存曲线，没有训练。原实验目录只读；所有新产物保存在本 run。精确值、逐 cell 来源路径与 SHA-256 均见同目录 `summary.json`。本节的小数和百分数为显示精度调整，未改变审计存档值。

## 可写入读者报告的结论

1. **这批任务的风险最低点并不要求训练误差先降到极低。** 在原 mixed-target 任务的 60 条期望风险曲线中，rise 时 noisy train MSE 仍为初始值的 **11%–88%，中位 42%**；以“低于初始值的 10%”这个事后描述阈值计算，**0/60** 通过。若改用同一次训练的 actual val 最低点，train 比例为 **10%–85%，中位 41%**，只有 **1/60** 低于 10%。此证据不能支持统一的 train-only 触发阈值。

2. **噪声造成的泛化损害在最低点之前就开始积累。** 在半个 t* 时，σ²N 已达到最低点处该项的 **52%–88%，中位 74%**；在连续最低点附近，**60/60** 曲线的 B 仍下降、σ²N 仍上升。风险尚在下降只说明信号学习收益暂时更大，并不代表尚未拟合噪声。这里的“积累”指风险分解里的噪声损害项，不等同于净 val 已回升。

3. **rise 的最低点与数学意义的拐点是两个位置。** 最低点是一阶导换号；二阶导由正转负的位置位于最低点之后，在本批曲线中约为 **1.2–8.1 倍 t*，中位 1.9 倍**。后者按保存整数网格的二阶差分定位，有一步量级的分辨率。

4. **光滑最低点附近应先用二次形状刻画。** 连续谱插值给出 R−Rmin≈½R″(t*)·Δt²；在 Δt/t*=0.001 时，**60/60** 曲线的实际增量与二次近似之比为 **0.997–1.000**，在 0.01 时为 **0.969–1.000**。旧指数约 **1.55** 是 x∈[0.1,1] 上的有限区间描述，不能替代最低点的局部形状，更不能外推整个尾部。

5. **同一次训练的 val 最低点与对训练噪声平均的风险最低点可相差很大。** 60 个 cell 的 actual val t* / expected-risk t* 为 **0.24–86.72，中位 1.37**。最大反例为 n32/seed414/σ²=0.25：actual val 最低点 **5550 步**，期望风险最低点 **64 步**，两者均为内部最低点。不能把期望曲线的比例系数直接当作单次 val 的比例系数。

## 数据与复核

`val` 是同一次保存 noisy-training realization 在独立合成 clean audit 标签上的 MSE，以保存的 eigenvectors、epsilon、谱统计重建；不是 benchmark test，也不是新训练。`expected_risk` 是固定输入/特征、对 iid 训练标签噪声取条件期望的 clean audit MSE。

核验所有 60 个 result JSON/NPZ 与 data NPZ 的源哈希，逐条对照原 `summary.json` 的最低点；所有原最低点差异为 **0**。重建 train 与保存 train 的最大绝对差为 **5.2e−13**；重建 actual val 的最后一步与保存 final head 的直接预测最大差为 **3.5e−12**；R=B+σ²N 最大误差 **0**。

这些都是原单个 mixed-target 任务上的 development 事后分析，没有增加跨任务证据。
