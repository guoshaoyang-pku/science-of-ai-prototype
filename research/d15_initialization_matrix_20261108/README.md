主要显示：同上下文、同 seed 的终点验证 MSE 相对均匀基线的比值，跨 seed 中位数；失败数量、训练 MSE≤0.1 的达到数与时间单独保留。相对改善不等于低绝对误差。线性模型不可达由最小二乘地板识别，其他模型不声称已知地板。精确零、近零、全零初始梯度、非有限结果分别记录。

ZAS-embed 是矩形推广构造（前层矩形单位嵌入、末层零），不是直接复现方形矩阵拟合收敛定理。无 bias；ReLU 零点导数采用 PyTorch 的 0。残差架构只有中间方形层为残差分支，第一投影和最终读出为线性；depth=2 时因此没有非线性。LayerNorm 无仿射参数，每个隐藏层激活前使用 eps=1e-5。架构比较包含这些训练函数变化，不是仅一个旁路的独立因果估计。
