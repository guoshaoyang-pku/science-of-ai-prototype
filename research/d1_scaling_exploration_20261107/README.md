## 分轮组织

1. `r001`：在可解析的旋转二次目标上，检验“同一初始位移坐标能否在改变梯度/曲率几何、更新历史和参数原点后保持同题跨初始化换算”。比较无拟合长度/投影坐标、历史标定一次/二次式与空预测，记录误差、覆盖率、首次/持续端点和反例。
2. 后续：将已辨识的因素迁移到深线性、非线性 MLP 和序列模型；控制函数不变参数化、固定/新数据、小批量、损失类型及目标可表示性。逐轮另行预注册，不把候选当已执行。
3. 结论整理：解析事实、实测规律与未证实机制分别报告。大范围开发扫描后，选定预测才使用新的确认 draw；新 seed 只表示重复性，不表示新任务。
