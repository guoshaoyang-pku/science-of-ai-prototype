# r003：总体风险的解析核对（计算前冻结）

问题：r002中7个无法判断的条件，究竟在输入总体上升还是下降？同时核对此前44个明确回升是否全部在总体上超过原门槛。只评价r002冻结的51对模型，3个边界仍保留；不训练、不重选点、不做可表示目标干预。

## 来源与推导

原始二阶矩采用Cho & Saul (2009), *Kernel Methods for Deep Learning*, §2.1, equations (1), (3), (6)。[NeurIPS原文](https://proceedings.neurips.cc/paper_files/paper/2009/file/5751ec3e9a4feab575962e78e006250d-Paper.pdf)。论文的kernel定义为两倍ReLU乘积期望；本轮所用K要除以2。这里只复用该矩公式，不声称原文验证过D2的现象。输入/权重交换角色来自标准高斯积分本身，不需要无限宽近似。

x~N(0,I4)，u_j=max(w_j·x,0)，r_j=||w_j||>0，θ_ij=acos(w_i·w_j/(r_i r_j))。固定特征为φ=((u−c)/s,1)，c和标量s必须沿用训练集的中心与尺度；不是总体中心/尺度。

| 矩 | 精确解析表达式 |
|---|---|
| μ_j=E[u_j] | r_j/√(2π) |
| K_ij=E[u_i u_j] | r_i r_j[sinθ_ij+(π−θ_ij)cosθ_ij]/(2π) |
| E[u_j x0] | w_j0/2 |
| E[u_j x0x1] | w_j0 w_j1/(r_j√(2π)) |
| Q=E[φφᵀ]的特征块 | (K−μcᵀ−cμᵀ+ccᵀ)/s² |
| Q的常数交叉列 | (μ−c)/s；右下角为1 |
| h=E[φy] | 特征部分为(E[ux0]+αE[ux0x1])/(s√(1+α²))，常数部分0 |

线性/交互矩的独立推导（本轮数学推导，不冒充论文结论）：设Z=w·x/r，则Z为标准高斯，E[x0|Z=z]=(w0/r)z，E[x0x1|Z=z]=(w0w1/r²)(z²−1)。分别乘rz并在z>0积分，得到w0/2与w0w1/(r√(2π))。归一化目标y=(x0+αx0x1)/√(1+α²)满足Ey=0、Ey²=1。

输出权重β的总体MSE为R(β)=βᵀQβ−2βᵀh+1。冻结前后权重βe、βl的净变化使用Δ=(βl−βe)ᵀ[Q(βl+βe)−2h]以减轻两个相近MSE相减的舍入误差。这是已知输入分布和已知目标下的总体积分，不是任意真实任务的train-only预测器。

## 独立校验

1. 对每份保存draw选固定8个特征对及夹角相关系数最小/最大的非对角对，使用条件高斯一维积分计算E[ReLU(U)ReLU(V)]。不是再次调用角度公式。
2. 每个特征用上述条件高斯一维积分核对线性/交互矩；另核对同向、反向、正交与w=(1,1,0,0)的符号/尺度。
3. 以原始ReLU系数a=β_hidden/s、b=β_const−β_hidden·c/s独立展开风险，与标准化矩结果比较；核对Q对称、半正定、R非负。
4. 原r002置信区间与解析Δ是否相容只作描述；这些区间是近似统计区间，不作为数学正确性的门槛，更不调整公式去迎合观测。

5. 全部51对模型以60位mpmath从原始特征坐标另行计算风险与差值，输入常数为保存的float数值，保存高精度字符串及与float64的差异。差异超过容差则数值未决。主门槛附近也按±容差分确认/反例/数值未决，不能把未决归为支持或反驳。
