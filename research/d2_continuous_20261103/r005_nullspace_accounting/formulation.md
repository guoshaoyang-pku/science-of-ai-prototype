# r005：训练样本看不见的部分，如何影响总体误差？

这是对r004的5个已选见证作记账与辨识核对，不增加任务，也不改变原训练过程。每个teacher仍是模型能表示的目标，但训练样本可能不足以辨认其全部参数。

在原参数坐标、原中心/尺度与Euclidean GD下，令P为训练特征矩阵Φ的行空间正交投影。将teacher b*拆为b_row=P b*及b_null=(I−P)b*。在精确零空间中Φb_null=0，所以g=φᵀb*与g_row=φᵀb_row在训练输入上的答案相同，零初始化全批量GD轨迹也相同；新输入上的答案则可能不同。这是不可辨认目标对照，不能称为修复原任务。

令e_row(t)=β_t−b_row。对原teacher的总体风险为：

| 部分 | 表达式 | 是否随时间变化 |
|---|---|---|
| 可学习部分的残余误差 | R_row=e_rowᵀQe_row | 是 |
| 训练样本看不见的部分 | R_null=b_nullᵀQb_null | 否 |
| 两部分如何互相抵消/叠加 | C=−2e_rowᵀQb_null | 是 |

R=R_row+R_null+C，因此ΔR=ΔR_row+ΔC。C<0表示两部分在总体平方误差里互相抵消。本轮强预测：5例都是R_row改善，但原先为负的C变得不那么负，增加量超过改善量。C由负转正、两端都正、或R_row自身也恶化，均保留并视为不同解释，不能事后合并成5/5成功。

不能把旧训练特征值cutoff直接当作真零空间。先对Φ做SVD，检查间隔、标签残差、轨迹一致性；再利用本数据的±配对及无偏置ReLU结构作独立高精度核对。每对输入的特征均值属于偶函数部分，差值属于4维线性输入部分，故行空间由n/2个偶行与4个W/s行张成（常数在偶行中）。原始参数以保存的二进制浮点值为常数，在60位精度下重建，不重新中心化。

对这些generic已保存输入，协议要求该结构基满行秩n/2+4且与SVD数值秩一致；若不一致，停止推断而不调整阈值。固定中心/尺度的float矩与精确ReLU计算只在舍入误差内相同，故需要标签残差和冻结终点动力学误差界一起通过，不能单靠秩间隔宣称严格零。
