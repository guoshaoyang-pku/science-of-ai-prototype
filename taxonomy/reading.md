# Where to Start Reading

Entry points into the literature, by what you want from the taxonomy. Full classification tables live in [`../survey/`](../survey/).

## If you want the ladder's L2 exemplars (laws done right)

1. Kaplan et al., *Scaling Laws for Neural Language Models* (2020) — the canonical fitted relation family.
2. Hoffmann et al., *Training Compute-Optimal Large Language Models* (2022) — Chinchilla reallocation; read with the validity boundary, not without it.
3. McCandlish et al., *An Empirical Model of Large-Batch Training* (2018) — gradient noise scale.
4. Cohen et al., *Edge of Stability* (2021) — a dynamical regularity, precisely scoped.
5. Yang & Hu, *Tensor Programs V* (2022) — μP/μTransfer: where a theory-motivated rule meets an empirical transfer law.

## If you want L3 attempts (mechanism, with honest boundaries)

1. Jacot et al., *Neural Tangent Kernel* (2018) — convergence in the infinite-width limit.
2. Chizat et al., *On Lazy Training* (2019) — the lazy/rich dichotomy as a theorem.
3. Bahri et al., *Explaining Neural Scaling Laws* (2021) and Maloney et al., *A Solvable Model* (2022) — conditional derivations of scaling behavior.
4. Saxe et al., *Exact Solutions to the Nonlinear Dynamics of Learning in Deep Linear Networks* (2014) — the solvable-model tradition.

## If you want the verification-gap evidence (why the gates matter)

1. Adebayo et al., *Sanity Checks for Saliency Maps* (2018) — methods failing their own tests.
2. Jain & Wallace, *Attention is not Explanation* (2019) — and the Wiegreffe–Pinter reply; read as a pair.
3. Makarenko et al., *Interpretability Illusion for Subspace Patching* (2023) — a constructive counterexample.
4. Geirhos et al. and the *verification gap* analyses of AI-scientist systems — peer review is not verification.

## If you want the producer axis (machine-made knowledge)

1. FunSearch (2023) and AlphaEvolve (2025) — program search with executable evaluators: the strongest Verify in the map.
2. AI Scientist v1/v2, Agent Laboratory — full-loop manuscript production, L1 output.
3. ExpeL, Voyager, Cheatsheet — agent memory: accumulation without gates.
4. Eureqa / AI Feynman, GNoME, AlphaFold — discovery machines in cheap-oracle domains: the existence proof that machine ascent works.
